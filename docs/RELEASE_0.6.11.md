# Mr.Robot 0.6.11

## 모델 실행 경로와 세션 효율

- PC·모바일·Discord가 사용하는 공통 실행 엔진을 조정했습니다. 명시적으로 본문을 제공한 번역·요약·교정·분류·추출 요청은 PC 도구 없이 처리합니다. Codex와 Claude CLI는 기존 격리 텍스트 경로를 사용합니다. 파일·웹·최신 정보·저장 요청은 이 단축 경로로 분류하지 않습니다.
- 이 단축 경로는 모델을 바꾸거나 본문 작업의 추론 수준을 낮추지 않습니다. 기존의 명백한 인사·단순 계산만 낮은 추론으로 처리하며, 복잡한 작업과 사용자가 선택한 오케스트레이션 프리셋은 유지합니다.
- 같은 대화의 요약·회상 질문도 대화 전용 세션을 이어 사용합니다. "다시 해" 같은 모호한 후속 명령이나 다른 대화·파일·실제 작업을 요구하는 문장은 임의로 회상으로 축소하지 않습니다.
- Codex 네이티브 작업 사이에 텍스트 대화가 끼어도, 저장된 대화 전체 접두부가 동일하면 같은 세션을 이어갑니다. 빠진 대화만 과거 기록으로 전달하며 완료된 작업을 재실행하지 않도록 구분합니다. 이전 기록 수정·모델·프로젝트·권한·도구·사용자 경계가 바뀌면 세션을 공유하지 않습니다.
- 변동하는 근거 문맥을 고정 시스템 지침과 분리했습니다. OpenAI Responses/호환 Chat, Anthropic API, CLI 텍스트/격리 실행에 동일한 문맥 전달 규약을 적용합니다. Codex 텍스트 세션은 바뀐 문맥만 전달하고 제거된 문맥은 명시적으로 해제합니다. 공급자 캐시 적중을 보장하지는 않습니다.
- 독립적인 텍스트 요청에서는 불필요한 프로젝트 지식 그래프 조회와 보조 에이전트 도구 준비를 생략합니다. 프로젝트 지침과 기존 대화는 유지합니다. 실제 프로젝트 작업에서는 기존 범위 제한 지식 조회와 검증이 작동합니다.
- 텍스트 전용 응답은 PC 실행 승인을 요구하지 않습니다. 후속/대기 입력이 PC 작업으로 바뀌면 실행 전에 기존 권한 검사를 수행합니다. 일반 Discord 사용자의 첨부·결과물 격리와 관리자 권한은 확대하지 않습니다.

## 검증과 범위

[실측 결과 및 검사 범위](OBSERVATION_0.6.11_2026-10-03.md)에 설치 앱의 동일 모델 전후 결과와 제한을 기록합니다. 새 회귀 검사는 공급자별 문맥 전달, 세션 접두부 검증, 문맥 변경/제거, 선택 모델·추론 유지, 후속 PC 명령의 승인, 티켓 격리를 다룹니다.

이는 실행 구조 튜닝이며 모델 가중치를 학습한 파인튜닝이 아닙니다. 유료 학습 작업·새 API 계정·사용자 문서 업로드를 시작하지 않았습니다. Claude의 장기 프로세스 재사용이나 모든 공급자의 속도 향상을 입증했다는 뜻도 아닙니다. 모바일 앱 버전 메타데이터는 맞추지만 APK/Drive/공개 Release 바이너리 배포는 별도입니다.

## 설계 근거

공개된 [OpenAI 지연 최적화 지침](https://developers.openai.com/api/docs/guides/latency-optimization)의 불필요한 호출·작업 감소, [프롬프트 캐싱 지침](https://developers.openai.com/api/docs/guides/prompt-caching)의 안정된 앞부분 유지, [Codex app-server 문서](https://learn.chatgpt.com/docs/app-server)의 thread/turn 재사용을 현재 권한 구조 안에서 적용했습니다. 공급자 문서는 설계 근거이며 실제 앱 성능 수치는 별도로 측정합니다.
