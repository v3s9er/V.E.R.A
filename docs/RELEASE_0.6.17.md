# Mr.Robot 0.6.17 통합 화면과 실시간 작업 로그

PC와 모바일의 대화 화면을 차분한 어두운 색상으로 통일했습니다. 분리된 상단 바를 본문과 연결하고, 입력창과 선택한 항목에는 얕은 그림자와 명암 차이를 주었습니다. 모델 실행 방식, 사용자 권한, 저장된 대화와 연결 설정은 변경하지 않습니다.

## 답변 대기 중에도 보이는 실행 기록

답변이 아직 출력되지 않을 때는 대화 본문에 실제 도구 실행 로그가 표시됩니다. 최근 6개 이벤트를 시간순으로 보여주며 실행 중·완료·오류를 구분합니다. 도구가 실행되지 않았다면 모델 응답을 기다리는 상태임을 표시하고 가상의 작업을 만들어 보여주지 않습니다. 답변이 도착하면 본문은 답변으로 전환되며 상세 작업 기록은 계속 펼쳐볼 수 있습니다.

PC와 모바일이 같은 이벤트 표시 규칙을 사용합니다. 로그에는 원시 도구 인자, 반환 JSON 또는 비공개 추론을 넣지 않습니다. PC의 메시지별 도구 기록에서도 원시 인자 미리보기를 제거했습니다.

## PC 화면

- Windows의 흰색 제목 표시줄을 어두운 앱 프레임으로 바꿨습니다. 기본 최소화·최대화·닫기 버튼과 드래그 영역은 유지합니다.
- 대화 제목·프로젝트 선택 영역의 별도 배경을 없애 본문과 자연스럽게 이어지도록 했습니다.
- 대화 목록이 길어지면 각 항목이 세로로 눌리던 문제를 수정했습니다. 대화 항목의 높이를 유지하고 목록 안에서 스크롤합니다.
- 높이가 낮은 창에서는 프로젝트 목록 높이를 줄여 대화 목록과 입력창 공간을 확보합니다.
- 실제 설치 패키지에서 CSS 로딩 순서에 따라 옛 상단 배경이 되살아나던 문제도 수정했습니다.

## 모바일 화면

- 별도 PC 연결 헤더와 대화 헤더를 한 영역으로 합쳤습니다. 대화 제목 아래 PC·프로젝트가 표시되며 PC 선택 버튼은 같은 헤더에 있습니다.
- 입력창, 작업 기록 패널과 선택된 탭의 명암을 조정했습니다. 하단 탭 아이콘도 단색으로 정리했습니다.
- 작업 중 추가 지시와 중단은 입력창 도구줄의 화살표·사각형 버튼으로 통합해, 별도의 큰 버튼 줄이 대화 공간을 차지하지 않도록 했습니다. 보조 기술에서는 기존의 전체 동작 이름으로 안내합니다.
- 키보드가 열리면 보조 정보를 줄이는 동작과 가로 화면의 간결한 작업 버튼을 유지합니다. 안전 영역과 중단 버튼의 가림 방지도 유지합니다.

## 검증 범위

전체 `npm test`, 타입 검사, 모바일 UI 계약·개인정보 검사와 공개 소스 검사를 통과했습니다. 소스·도달 가능한 Git 이력·PC 패키지·압축 해제한 APK에서 로컬의 알려진 자격증명과 일치하는 값이 검출되지 않았습니다. 알려지지 않은 모든 비밀정보의 부재를 보증하는 검사는 아닙니다.

웹 UI는 7개 크기에서 입력·중지·추가 지시·프로젝트·모델 선택을 검사했습니다. 별도 검사에서는 대화 62개의 목록 높이·스크롤, 본문의 도구 로그, 답변 전환과 투명한 상단 배경을 확인했습니다. 캘린더 탐색과 마지막 날짜 접근도 회귀 검사했습니다.

실제 Electron 테스트 앱에서 Windows 기본 창 버튼의 표시, 드래그 영역, 입력창 위치와 통합된 상단 배경을 확인했습니다. 렌더러 강제 종료 후 화면 복구와 에이전트 프로세스 유지도 확인했습니다.

별도의 Android 네이티브 UI 테스트 앱에서 실제 키보드를 반복해서 열고 닫았습니다. 세로·가로 화면과 글자 크기 100%·150%의 네 조건 모두에서 다중 행 입력 커서와 중단 버튼의 가림 검사를 통과했습니다. 테스트 앱은 실제 화면 컴포넌트와 모의 RPC를 사용합니다.

Android 릴리스 APK는 0.6.17, versionCode 45입니다. 기존 인증서 서명, 현재 앱 소스 18개 모듈과 공용 소스 5개 모듈의 포함 여부, 에뮬레이터 설치·기동을 확인했습니다. 물리 휴대폰과 외부 LTE 연결은 이번 UI 검사의 대상이 아닙니다. Windows 설치 파일은 Authenticode 미서명이므로 SmartScreen 경고가 나올 수 있습니다.
