# Mr.Robot 0.6.0 — 측정 가능한 성능 개선과 모델 튜닝

2026-09-23. 이 문서는 소스/설치 빌드의 변경 내역이며, GitHub 게시 여부는 별도로 확인해야 합니다.

## 사용자 기능

- PC·웹 관리자의 **설정 → 튜닝 · 성능**에서 공급자별 프로필을 생성·수정·삭제하고 저장/적용/기본값 복귀를 구분합니다. 다음 단일 모델 요청부터 적용합니다.
- 추론, 답변 길이, 보조 작업 사용 여부와 동시 작업 수를 조절합니다. 지원하는 API 모델은 출력 토큰과 temperature도 설정할 수 있습니다. 모델·권한·질문 예산은 바꾸지 않습니다.
- 입력창에서 직접 고른 추론 단계가 우선합니다. 시나리오별 라우팅은 유지합니다. 지원하지 않는 옵션은 실제 요청 전 차단하고 수정 방법을 안내합니다.
- 첫 응답/완료 시간의 중앙값과 P95, 측정 개수, 성공·취소, 모델별 사용량을 표시합니다. 첫 응답을 관측하지 못한 기록을 0초로 표시하지 않습니다.
- 좁은 창에서는 한 열로 배치합니다. 미저장 편집을 보호하고 PC/공급자 변경 시 늦게 도착한 응답이 새 화면을 덮어쓰지 않게 했습니다.
- 손상된 튜닝 설정은 해당 부분만 비활성화하고 원본을 보존합니다. 다른 계정 설정을 과거 백업으로 되돌리지 않습니다.

## 실제 성능·안정성 변경

- 매 실행마다 통계 파일 전체를 다시 파싱하던 경로를 제한된 메모리 캐시와 추가 기록 방식으로 변경했습니다. 외부 수정 감지, 크기 제한, 손상 행 격리, 원자적 교체를 유지합니다.
- 1,000개 합성 기록의 같은 로컬 작업에서 저장 p50은 2.187→0.465ms, 통계 조회 p50은 1.469→0.041ms였습니다. **모델 추론 전체가 이 비율만큼 빨라졌다는 뜻은 아닙니다.** [측정 조건과 결과](performance-results-2026-09-23.md)
- 통계 저장 실패 때문에 이미 완료한 정상 답변을 실패로 표시하지 않습니다. 실제 공급자 오류와 부분 사용량은 보존합니다.
- 도구 호출 수는 과거 대화 전체가 아니라 이번 요청만 셉니다. 실패한 실행도 실제 관측된 모델에 귀속하며 복수 모델은 별도 표시합니다.
- 보조 문맥을 설정한 예산 내에서 보수적으로 제한하되, 원문 대화와 도구 호출/결과 쌍은 변경하지 않습니다. 장기 기억의 중복 조회도 제거했습니다.

## 로컬 파인튜닝

- 네이티브 PC의 로컬 관리자만 명시적으로 JSONL을 가져와 검증하고 학습/평가 자료로 분리할 수 있습니다. 화면 가져오기는 256KB, 내부 검증 모듈은 최대 2MiB입니다.
- 중복/출처 그룹 분리, 비밀키 차단, 개인정보 검토, 경로·체크섬 검증을 제공합니다. 기존 대화/Discord 티켓/첨부를 자동 수집하지 않습니다.
- 설치본에 별도의 로컬 LoRA/NF4 학습 스크립트와 안내서를 포함합니다. 기본은 dry-run이며 로컬 모델·의존성·사용자의 명시적 실행이 필요합니다. 모델 다운로드·자동 설치·외부 전송·자동 적용은 하지 않습니다.
- **Codex·Claude 구독 모델의 가중치를 학습하는 기능이 아닙니다. 실제 GPU 학습이나 학습 후 품질 향상은 이번 검증에서 수행하지 않았습니다.** [사용법과 한계](local-finetuning.md)

## 재현 가능한 평가

로컬 처리, 합성 네이티브 전송, 실제 구독 모델 평가를 분리합니다. 성공률·토큰·첫 응답·꼬리 지연을 함께 기록하며, 표본 부족이나 품질 저하가 있는 후보를 자동 승격하지 않습니다. 실제 구독 실험은 명시적 사용량 동의 플래그가 필요합니다. 개인 대화/파일을 실험 입력이나 보고서에 넣지 않습니다.

```powershell
npm run typecheck
npm run test:tuning
npm run test:performance
npm run test:coordination
npm run test:local-training
```

[평가 실행법과 논문/GitHub 근거](performance-evaluation.md). 이 작은 합성 과제들은 일반 코딩·컴퓨터 제어·장기 계획 성능을 대표하지 않습니다.

## 배포 범위

Windows x64 설치본과 기존 공식 키로 서명한 Android APK(versionCode 30)를 빌드합니다. Android 앱에는 이번에 별도 학습 UI를 추가하지 않았으며, 연결된 PC의 실행 개선을 이용합니다. Windows 설치본은 아직 코드 서명 인증서가 없는 개발 빌드입니다.

0.5.0의 [단일 모델 보조 작업·원문 대화 보존·MCP 지연 조회](agent-coordination.md)도 포함합니다. 대화·연결 정보·토큰·학습 자료·모델 가중치는 배포 파일에 포함하지 않습니다.
