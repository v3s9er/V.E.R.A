# Mr.Robot 0.4.8 — Discord 최근 메시지 제어 메뉴

- Discord Agent 1.3.0: 기존 봇 연결정보만 읽는 독립 모드 추가. 기존 시큐리티봇 소스·GUI·뉴스·KTX 없이 실행합니다. 기존 기능과 단일 연결로 함께 실행하는 호환 모드도 선택 가능합니다. 계정별 OS 잠금 및 기존 봇 IPC 충돌 차단, 비밀정보 미복사, 설정 검증 실패·작업 중 설정 변경 시 기존 실행 보호를 포함합니다. 다른 PC의 중복 실행 감지나 호환 모드에서 GUI를 유지하는 AI 핫 분리는 지원하지 않습니다.
- 티켓의 일반 메시지 접수·오류·최종 응답 아래에 중지/모델/권한 제어 메뉴를 제공합니다. 새 메뉴를 보낸 뒤 이전 메뉴의 버튼만 제거하고 메시지 본문은 유지합니다. 이전 View를 종료하고 삭제된 세션의 메뉴 참조도 정리합니다.
- `/robot controls`: 현재 티켓의 제어 메뉴를 맨 아래로 다시 표시. `/robot model`: 공급자·모델·추론 선택창을 직접 표시.
- 모델 ID 직접 입력 대신 등록 공급자 및 해당 공급자가 발견한 모델을 드롭다운으로 선택합니다. 25개 단위 페이지, 긴 모델 ID 보존, 발견 실패 시 등록 모델 안내를 지원합니다. 선택은 티켓별로 저장합니다. 모델 발견이 연결 성공을 보장하지는 않습니다.
- 권한 드롭다운은 제어 메뉴에 바로 표시합니다. 전체 PC 허용은 별도 동의가 필요하고 실행 중 권한/모델 변경은 기존 정책에 따라 거절됩니다. 중지 후 바꿀 수 있습니다. 중지는 취소이며 일시정지 후 동일 실행 재개 기능을 의미하지 않습니다.
- 승인 요청에도 작업 중지 버튼을 추가했습니다.
- Python 브리지와 호스트가 같은 로컬 허용 서버 목록을 사용합니다. 가입만으로 허용하지 않으며 명시적으로 허용한 여러 서버만 동작합니다. 읽기 실패·손상·빈 목록은 차단합니다.

Discord 메시지 컴포넌트를 화면 자체에 고정하는 방식은 아닙니다. 최신 봇 메시지 아래에 메뉴를 재배치하며 사용자가 과거 기록을 스크롤하면 `/robot controls`로 다시 꺼낼 수 있습니다.

Python 제어 메뉴·모델 페이지·소유권·허용 서버 회귀, 호스트 Discord/예산 테스트와 타입/설치 파일을 검증합니다. 이번 작업은 로컬 Windows 업데이트이며 새 GitHub/APK 배포는 별도입니다. 서버 ID와 토큰 등 런타임 설정은 포함하지 않습니다.
