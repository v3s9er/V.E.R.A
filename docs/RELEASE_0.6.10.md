# Mr.Robot 0.6.10

## 도구 실행과 문맥 효율

- API 에이전트의 연속된 파일 읽기·목록 조회를 최대 3개 작업 레인으로 처리합니다. 하나가 끝나면 다음 읽기를 즉시 시작해 느린 읽기 하나 때문에 빈 레인이 기다리지 않습니다. 결과 순서는 유지하고 쓰기·화면 조작·미확인 플러그인은 앞선 읽기가 모두 끝난 뒤 순서대로 실행합니다.
- MCP 도구 탐색에 `serverId + query` 키워드 검색을 추가했습니다. 목록 전체를 대화에 여러 번 넣지 않고 상위 요약을 찾은 뒤 선택한 도구의 schema만 요청합니다. 네이티브 CLI에도 기존 호스트 MCP 도구를 통해 제공됩니다.
- 목록 갱신 중 진행되던 응답이 오래된 schema 캐시를 되살리지 못하도록 세대 검사를 추가했습니다. 검색 페이지 수·출력·캐시 제한, 승인·취소 경계는 유지합니다.

## Claude API 스트림 호환성

- 텍스트/추론 블록 뒤에 도구 호출이 올 때 실제 이벤트 index에 인자를 연결하도록 수정했습니다. 여러 도구의 JSON 조각도 각각 조립합니다.
- 잘린 JSON, 중복·미완료 도구 블록, 오류 또는 종료 신호 없는 스트림은 실행 가능한 도구 이벤트로 내보내지 않습니다. 모델 응답 완료 전 도구를 추측 실행하지 않습니다.
- 이 부분은 Anthropic Messages API 어댑터 수정이며 Claude CLI 자체를 변경하지 않습니다. [공식 스트리밍 프로토콜](https://platform.claude.com/docs/en/build-with-claude/streaming)을 기준으로 독립 구현했습니다. 외부 비공개 소스나 압축 파일을 제품·Git에 포함하지 않습니다.

## 범위

Windows 에이전트/웹 업데이트입니다. 모바일 버전 표시는 저장소 일치 규칙에 따라 0.6.10(versionCode 38)으로 맞추지만 신규 APK·Drive 업로드·GitHub Release 바이너리 게시는 포함하지 않습니다. 모델·추론·Daybreak 기본값, PC/Discord/모바일 권한은 바꾸지 않습니다.

합성 검증과 실제 성능 주장의 경계는 [검사 기록](OBSERVATION_0.6.10_2026-10-03.md)을 참고하세요. 파인튜닝 또는 전반적 모델 정확도 향상으로 해석하지 마세요.
