# V.E.R.A 0.7.8

## 작업 근거 검색 개선

- `@scope/name`, `packages/api`, `service.api` 같은 식별자를 통째로 검색합니다. 이름 일부가 겹치는 다른 항목이 섞이거나, 없는 항목을 물었을 때 무관한 `status` 기록을 가져오는 문제를 수정했습니다. 한국어 식별자·조사, 의도적인 넓은 검색과 본문 속 정확한 이름 검색은 유지합니다.
- 질문에서 지목한 대상과 그 대상의 상태·소유자 등 직접 사실을 먼저 보존합니다. 오래된 모순 값이 최신 가지에 밀리지 않게 하고, 연결이 적은 의존관계 경로를 넓은 공통 소속 노드보다 먼저 탐색합니다.
- 관련 근거를 생략했다면 계속 불완전한 검색으로 표시합니다. 기존의 128개 원시 사실·6단계 탐색·512개 전체 사실·7,000바이트 문맥 한도를 유지하며, 완전한 그래프 검색을 보장하는 기능은 아닙니다.
- 모델·추론 설정·실행 모드·권한은 바꾸지 않습니다. 이 검색 알고리즘 자체는 모델을 추가 호출하지 않습니다. Discord의 관리자 지정 단일 모델 경로와 비공개 지식의 접근 경계도 유지합니다.

## 검증 결과와 한계

합성 검색 회귀검사 24개에서 기존 0.7.7은 4개, 개선판은 24개를 통과했습니다. 이는 매개변수를 바꾼 **검색 알고리즘 검사**이며 24개의 독립적인 고난도 문제나 모델 정답률이 아닙니다. 정확한 식별자 검색의 근거 문맥은 약 5.3–5.5KB에서 467–470바이트로 줄었습니다. 반면 추가 색인 때문에 1만 건의 초기 색인 생성 비용은 늘어났습니다. 따라서 검색 전 과정이 항상 빨라졌다는 뜻은 아닙니다.

실제 앱의 renderer → `chat.start` → Codex 구독 경로에서도 별도로 비교했습니다. 같은 `gpt-6-sol`, `high`, 합성 질문 3개, 질문당 1회, 버전별 독립 임시 프로필을 사용했습니다. 사실은 `memory.add`로 저장하고 질문에는 반복하지 않았습니다. 기존 설치 아카이브와 개선판 스테이지를 개발용 Electron에서 실행했으며 사용자 프로필은 사용하지 않았습니다.

세 문항 합계 토큰은 129,452에서 85,942로 줄었지만, 마지막 문항은 더 느리고 토큰도 조금 늘었습니다. 마지막 문항의 초기 근거에서는 기존에 없던 추론 사실 3개와 모순 1개가 개선판에 포함됐습니다. 정상 도구 사용이 허용되므로 최종 정답과 초기 검색 품질은 서로 다른 지표입니다.

**정답률은 3/3으로 같으며 일반 정확도 향상, 모든 작업의 속도 향상, 단일 Codex/Claude Code 대비 우위는 입증하지 않았습니다.** 기존판부터 순차 실행했고 공급자 부하·캐시를 완전히 통제하지 않았으므로 이 작은 표본의 시간 차이를 확정적인 속도 개선율로 해석하면 안 됩니다. 처음 시도한 기존판 검사는 테스트 자료 입력 중 요청 속도 제한에 걸려 추론 없이 중단됐습니다. 앱의 제한을 풀지 않고 테스트 입력만 250ms 간격으로 조정한 뒤 두 버전을 같은 조건으로 실행했습니다. 자료 준비 시간은 위 응답 시간에서 제외했습니다.

문제별 실제 결과와 검색 회귀검사를 분리하는 방식은 [OpenAI 평가 가이드](https://developers.openai.com/api/docs/guides/evaluation-best-practices)를 참고했습니다. 재현 절차와 측정 한계는 [성능 평가 문서](performance-evaluation.md#stored-knowledge-recall-regression)에 있습니다. 원시 답변·로컬 평가 기록은 공개 배포에 넣지 않습니다.

## 회귀 검사 및 배포 범위

온톨로지·근거 검색 71개, 오케스트레이션 140개, 튜닝 47개, 평가 도구 91개, 데스크톱 복구 19개 검사를 통과했습니다. Discord 권한·사용자별 모델 지정·첨부·격리, 암호화 전송 회귀 검사와 PC·웹·모바일 타입 검사도 통과했습니다. 이 수치는 서로 다른 기능 검사이며 합산한 모델 성능 점수가 아닙니다.

Windows 데스크톱과 PC 에이전트 업데이트입니다. 새 APK는 배포하지 않으며 공개 Android APK는 0.7.2(versionCode 48)를 유지합니다. 모바일 소스 버전만 0.7.8로 동기화하며 다음 APK 배포 전에 versionCode를 올려야 합니다. 기존 설치 ID·프로필·페어링, MIT 라이선스 및 제3자 고지를 유지합니다. Windows 설치 파일은 미서명입니다.

사용자별 모델·추론 지정값과 대화는 마이그레이션하거나 초기화하지 않습니다. 사용자 정보·실제 사용자 ID·자격증명·개인 백업·평가 원문은 공개 소스 및 배포 대상에서 제외하고 알려진 민감정보 패턴을 검사합니다. 이 검사가 모든 종류의 미지의 비밀값 부재를 보장하는 것은 아닙니다.
