# Mr.Robot 0.4.3

0.4.3은 정상적인 모델 사용량을 호출 전 보수적 추정치와 비교해 잘못 중단하던 문제를 고치고, 같은 실패 요청을 재시도할 때 대화 화면이 중복 행으로 쌓이지 않도록 보강한 안정화 릴리스입니다.

## 토큰 정책

- 개별 모델 호출의 사전 예약량은 동시 실행을 조절하기 위한 추정치로만 사용합니다.
- Codex CLI나 공급자가 자체 시스템 프롬프트·캐시 문맥을 추가해 실제 사용량이 개별 추정치를 넘더라도, 이미 확보한 전체 실행 예산 안이면 작업을 계속합니다.
- 전체 실행 예산을 실제 사용량이 넘으면 즉시 중단하고 초과량 전체를 15분 사용량 부채로 기록합니다.
- 전체 15분 창 10,000,000토큰, 관리자 8,000,000토큰, 연결 기기 500,000토큰 상한과 동시 실행·시작 횟수 상한은 그대로 유지합니다.
- 에이전트 지침은 정상 범위의 토큰 절약보다 정확하고 완결된 결과를 우선하며, 이미 통과한 전체 회귀 테스트는 기반 변경이 없는 한 반복하지 않도록 명시했습니다.

## 재시도와 중복 방지

- 직전 화면 끝이 동일한 사용자 요청과 실패한 assistant 응답인 경우에만 그 실패 pair를 새 시도로 교체합니다.
- 성공한 동일 요청이나 다른 요청은 기존처럼 새 메시지로 보존합니다.
- 모바일은 React 상태 반영 전 빠른 이중 탭도 동기 잠금으로 막아 `chat.start`가 두 번 호출되지 않게 했습니다.
- 데스크톱 재연결과 예약 작업에는 동일 요청 자동 재전송 경로가 없습니다.

## 검증 범위

- Agent/Web/Mobile 타입 검사 및 빌드
- 모델 실행 admission 정책의 관련 보안 테스트
- 데스크톱·모바일 UI 계약 테스트
- 개별 추정치 초과 30토큰 정상 허용과 전체 실행 예산을 넘는 10,000,001토큰 보고의 fail-closed 동작

전체 0.4.2 회귀 테스트는 직전 릴리스에서 통과했으며, 이번 변경에서는 영향을 받은 경로만 다시 검증했습니다.
