# Mr.Robot 0.6.9

## 실제 프로젝트 작업에 지식 연결

- 선택한 npm 프로젝트의 package.json/workspace 패키지에서 이름·상대 위치·내부 의존 관계를 자동 구성합니다. 사람이 사실을 미리 입력하지 않아도 변경 영향 분석에 근거가 들어갑니다.
- 출처 경로·해시를 유지하고, 저장한 주장과 현재 선언이 다르면 충돌로 남깁니다. 요청마다 새로 읽고 영구 기억을 자동 덮어쓰지 않습니다.
- “그거 바꾸면?” 같은 지시어 후속 질문은 직전 사용자 요청으로 관련 지식을 찾습니다. 대화 전체나 AI의 추측을 지식으로 저장하지 않습니다.
- API/네이티브 실행에 범위가 고정된 읽기 전용 `knowledge_lookup` 도구를 연결했습니다. 작업 중 다른 대상을 조회하거나 변경된 manifest를 다시 확인할 수 있습니다.
- 설정 → 기억 → 프로젝트 지식의 검사에서도 자동 구성된 선언을 확인할 수 있습니다.

## 경계와 호환성

- 자동 읽기는 선택한 프로젝트의 제한된 패키지 선언만 대상으로 합니다. PC 전체 문서·비밀 파일 수집이나 스크립트 실행이 아닙니다. npm 외 생태계는 기존 명시적 지식 저장을 사용합니다.
- PC 전체 허용과 지식은 별개입니다. 설치본 사용자 설정은 전체 허용을 확인하지만 제품 기본 권한·Discord 일반 사용자 격리·연결 기기 상한은 변경하지 않습니다.
- 단순 인사는 기존 도구 없는 경로를 유지하며, 지식 도구 때문에 모델을 바꾸지 않습니다.
- Windows 에이전트/웹 업데이트입니다. 저장소의 버전 일치 규칙에 따라 Android 버전 표기도 0.6.9(versionCode 37)로 맞췄지만, APK 신규 제작·Drive 업로드·GitHub Release 바이너리 게시는 이번 범위에 포함되지 않습니다.

실측과 남은 한계는 [검사 기록](OBSERVATION_0.6.9_2026-10-03.md), 구현 범위는 [온톨로지 문서](ontology.md)를 참고하세요. 이 변경은 파인튜닝이나 모든 작업의 정확도 향상을 의미하지 않습니다.
