# Mr.Robot 0.4.14 — Discord 응답·파일 첨부

- 티켓의 접수 메시지를 실제 답변으로 바꿉니다. 모호한 “처리 종료” 문구로 결과를 덮어쓰지 않습니다.
- 슬래시 요청도 같은 채널의 봇 메시지로 결과를 표시하여 긴 작업의 interaction 토큰 만료로 답변이 사라지는 문제를 막습니다.
- 긴 답변은 채널에 나눠 표시하고 매우 긴 본문은 전체 텍스트 파일도 제공합니다.
- 중단·승인·설정 성공·실패의 제어 JSON을 자연어로 표시합니다. 사용자가 실제로 요청한 일반 JSON 데이터/코드까지 제거하지는 않습니다.
- “PDF를 이 채널에 올려줘”처럼 명시적으로 전송을 요청하면, 답변에 확인된 PC 파일을 Discord 첨부로 보냅니다. 기존 서버 관리자 인증과 대화별 전체 접근 권한이 필요하며 PC 읽기 전용 잠금은 우선합니다.
- 파일은 해당 대화에 기록된 작업 폴더/Downloads 항목으로 제한하고, 인증 저장 경로·키 파일·폴더 탈출을 차단합니다. 파일 변경/크기/조각 순서를 확인하고 업로드 직전에 권한을 다시 검사합니다.
- 첨부 한도는 서버의 Discord 한도와 앱의 파일당 25MiB 중 작은 값, 응답당 최대 3개입니다. 초과 시 모바일 암호화 전송을 안내합니다.
- Discord 첨부는 Discord 서버에 저장됩니다. 종단 암호화가 필요한 파일은 모바일 앱의 보안 파일 전송을 사용하세요.
- `/robot result`는 재시작 후에도 해당 사용자·채널에 연결된 마지막 저장 답변을 조회합니다.

검증: Python Discord 테스트 53개, Node Discord 권한/세션/모델 정책, 파일 바이트·크기·경로·변경 거부 및 기존 암호화 전송 테스트, 전체 타입 검사. 실제 Discord 채널에 테스트 파일을 게시하지 않고 모의 채널과 실제 로컬 파일로 검증했습니다. 앱 버전 0.4.14, Discord 플러그인 1.4.2, Android versionCode 22입니다. 모바일 UI는 0.4.13의 수정 사항을 유지합니다.
