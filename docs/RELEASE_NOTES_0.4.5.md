# Mr.Robot 0.4.5

## Discord Agent (선택형 플러그인)

- 기존 로컬 Discord 봇에 `/robot ask`, `stop`, `new`, `status`, `models` 명령을 연결합니다. 기존 뉴스·트레이·열차 GUI를 그대로 실행합니다.
- 봇 애플리케이션 소유자만 호출할 수 있습니다. 결과와 승인 버튼은 ephemeral 응답이며 다른 구성원에게 공개하지 않습니다.
- 일반 `ask` 권한의 로컬 연결과 적응형 토큰 정책을 사용합니다. PC 관리자 자격증명은 Discord/Python에 전달하지 않습니다.
- 변경 작업 승인·거절, 채널별 대화, 모델/추론 선택, 중지, 연결 해제 시 작업 취소·자격 회수를 지원합니다.
- 기존 봇 소스와 Python은 별도 로컬 의존성입니다. 플러그인에서 경로 및 자동 연결을 설정합니다. 토큰·설정·로그·DB는 설치본과 공개 소스에 포함하지 않습니다.
- 기존 Discord 명령 전체를 덮어쓰지 않고 `/robot`만 등록합니다. 명령 전파에는 시간이 걸릴 수 있습니다.

## 통합과 UI

- 원격 main의 0.4.4 적응형/네이티브 감사 정책과 보안 작업대 변경을 보존했습니다.
- PC 실행 창·트레이·웹 로고를 모바일과 같은 브랜드 자산으로 통일했습니다.
- 입력창의 권한·추론 드롭다운과 기기별 권한 상한 표시, 모바일 IME 겹침 측정 개선을 통합했습니다. Android 패키지는 0.4.1 소스를 유지하며 이 릴리스에서 새 APK를 배포하지 않습니다.
- fflate 0.8.3 및 공유 패키지 우선 빌드 순서를 유지합니다.

## 검증과 제한

- Shared/Agent/Web/Mobile 타입 검사, 회귀 테스트 묶음, Discord 가짜 서버 통합 테스트 및 누수 검사를 수행했습니다.
- Discord 소유자 차단, 승인 ID 연결, 완료·중지·권한 회수, 실제 Gateway 로그인 및 명령 등록을 확인했습니다. 실제 사용자의 Discord 명령으로 모델을 실행하는 최종 동작은 사용자가 확인해야 합니다.
- Windows 설치본은 미서명입니다. 코드 서명 인증서는 포함하지 않습니다.
- Discord는 메시지를 처리하는 제3자 서비스입니다. ephemeral은 종단간 암호화가 아니며 민감한 자료를 보내지 않는 것이 좋습니다.

자세한 설정은 [Discord 플러그인 안내](../integrations/discordbot/README.md)를 확인하세요.
