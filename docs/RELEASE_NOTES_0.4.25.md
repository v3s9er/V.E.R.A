# v0.4.25 — Codex 모델 목록 진단·갱신 개선

## 모델 조회

- Codex는 CLI 도움말이나 `gpt-숫자` 정규식이 아니라 **app-server `model/list`**의 페이지별 응답을 사용합니다. 이 조회 방식은 v0.4.21부터 적용되어 있으며, 이번 버전에서 진단과 실패 처리를 보완했습니다.
- `gpt-6-astra`, `gpt-daybreak-blue-latest` 및 향후 숫자로 시작하지 않는 모델 ID도 CLI가 반환하면 표시합니다. 숨김 모델은 기본 선택창에서 제외합니다.
- Codex 조회에 실패했을 때 오래된 고정 기본 목록을 최신 목록처럼 표시하지 않습니다. 이전에 성공한 목록 또는 현재 저장된 모델만 유지하고 실패 상태를 안내합니다.
- **설정 → 모델 모듈**에서 조회 출처, 실제 사용한 Codex CLI 버전, 모델 수, 마지막 성공 시각을 확인할 수 있습니다. 모델 새로고침은 선택한 모델이나 대화 세션을 변경하지 않습니다.
- 시작·모델 선택창 진입 시 캐시를 확인하고, 5분이 지나면 다시 조회합니다. ↻ 또는 설정의 새로고침으로 수동 조회할 수 있습니다. 중복 요청은 합치고 연속 클릭은 제한합니다.
- 미설치/실행 실패, 구형 CLI의 미지원 명령·옵션, 시간 초과, 빈 모델 목록을 구분하여 안내합니다. 원시 CLI 로그, 인증정보, 사용자 실행 경로는 진단 응답에 넣지 않습니다.
- 구형 PC에 연결한 클라이언트는 기존 모델 목록 조회를 유지하고, 갱신 상태를 확인하려면 연결 대상 PC를 업데이트하라는 안내를 표시합니다.

## 다른 PC에서 새 모델이 없을 때

1. **실제로 AI를 실행하는 PC**에 이 버전의 Mr.Robot 설치 파일을 적용합니다. 다른 PC를 업데이트해도 근무지 설치본이 자동으로 바뀌지는 않습니다.
2. **설정 → 모델 모듈 → 모델 새로고침**에서 조회 결과를 확인합니다.
3. CLI 미지원 안내가 나오면 그 PC에서 Mr.Robot이 사용하는 Codex CLI를 업데이트하고 다시 조회합니다. 로그인/계정의 모델 사용 권한도 확인합니다.

모델 목록에 이름을 강제로 추가한다고 해당 계정에 모델 사용 권한이 생기지는 않습니다. Mr.Robot은 공급자의 목록을 따르며, API 키 결제로 자동 전환하거나 구독 권한을 우회하지 않습니다. 목록 조회와 CLI 버전 확인은 AI 대화나 추론 실행을 만들지 않습니다.

공식 조회 사양: [Codex app-server model/list](https://learn.chatgpt.com/docs/app-server#list-models-modellist).

## 함께 포함된 기존 main 변경

- 이전 공개 릴리스 이후 main에 추가된 선택형 Page Publisher 모듈을 보존했습니다. 기본 OFF이며 자동 외부 게시를 하지 않습니다. 개인 페이지 원본·프런트엔드 산출물은 포함하지 않습니다.

## 검증·배포

- Astra/Daybreak ID, 페이지 나누기·중복 제거·숨김 모델 제외, 구형 CLI 오류·시간 초과·빈 목록, CLI 버전 필터링, 캐시 신선도/실패 복구/동시 요청, 구형 PC 호환 UI 테스트.
- Windows의 Codex CLI 0.153.4에서 실제 7개 모델 반환을 확인했습니다. 설치된 0.4.25 앱의 Astra·Daybreak 드롭다운 표시와 수동 새로고침 완료·현재 선택 유지도 확인했습니다.
- 에이전트·웹·모바일 타입 검사, UI 계약 테스트, 공급자 권한 테스트, Page Publisher 기본 OFF 테스트, 공개 소스 및 설치 파일 민감정보 검사를 통과했습니다. 물리적으로 접근할 수 없는 다른 PC의 동작까지 보장하는 검증은 아닙니다.
- 공급자 조회의 관리자 권한 경계는 유지합니다. Discord 사용자별 모델 제한과 PC 접근 권한은 변경하지 않습니다.
- PC 설치 마법사(EXE), 소스 ZIP, SHA-256 체크섬 제공. 모바일 코드는 변경하지 않았으며 기존 v0.4.22 APK를 유지합니다.
- 근무지 PC 자체의 설치 상태나 계정 권한은 원격으로 검증하지 않았습니다.
