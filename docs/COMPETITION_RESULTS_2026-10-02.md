# 대회 문제 검사 결과 — 2026-10-02

## 범위

Mr.Robot 0.6.1 런타임 소스 `3d8f7f3`의 실제 AgentLoop와 격리된 Codex 구독 경로로 수행한 자체 검사다. 모델은 정확히 `gpt-6-sol`, CLI는 `0.159.3`, 추론 요청은 `auto`였으며 완료한 문항의 실제 선택은 모두 `medium`이었다. Daybreak는 끄고 도구·검색·PC 파일·개인 문맥을 제공하지 않았다. 도구 없는 단일 모델 경로의 결과이며, 모든 도구·오케스트레이션을 사용한 최고 성능을 측정한 것은 아니다.

고정 데이터 리비전·정답 분리·엄격한 채점·재현 명령과 한계는 [검사 프로토콜](competition-evaluation.md)을 따른다. 기존 앱 설정이나 설치본은 변경하지 않았다. 문제마다 새 세션, 1회 시도, 120초 제한이다. 두 연도의 실행 사이에 프롬프트·런타임·채점기를 변경하지 않았다.

2024년: I 15/15, II 15/15. 시간 초과·형식 오류·전송 오류·미실행은 모두 0개다. 첫 텍스트 중앙값은 9.00초, P95는 39.22초다. 정답 숫자만 응답하도록 했으므로, 첫 텍스트 시간이 일반 대화의 진행 안내 시간이나 첫 추론 이벤트 시간을 뜻하지 않는다.

2024년 보고된 입력 토큰은 101,427, 출력 토큰은 14,820이며 캐시 입력 46,208은 입력 합계에 이미 포함되어 있다. 전부 계측된 30개 문항의 입력+출력을 정답 수로 나눈 값이 표의 토큰/정답이다. 구독 비용이나 실제 과금액으로 환산하지 않았다.

2023년: I 14/15, II 14/15. `2023-AIME-I-06`, `2023-AIME-II-15`는 최종 텍스트 없이 120초 제한에 도달했다. 완료한 28개는 정답이었고 형식 오류는 없었다. 첫 텍스트 중앙값은 8.85초, P95는 25.89초지만 **텍스트가 온 28개만의 통계**다. 시간 초과 2개의 토큰 계측은 없어 전체 토큰/정답은 미상으로 남겼다. 0으로 간주하거나 완료한 문항만으로 전체 비용을 계산하지 않았다.

### 실패 문항 재확인 — 최초 점수에 합산하지 않음

실패 원인을 좁히기 위해 원본 검사 종료 후 동일한 모델·추론·문제·시간 제한으로 문항별 1회씩 재확인했다. 이는 실패 사례를 본 뒤 선택한 사후 진단으로, 새 holdout이나 pass@1 개선 점수가 아니다. 참조 정답은 모델에 보내지 않았다.

`2023-AIME-I-06` 재확인은 약 10.33초에 끝났지만 **오답**이었다. 최초의 시간 초과가 항상 재현되는 것은 아니지만, 빨라졌다고 정합성 문제가 해결된 것은 아니다. 참조 정답은 독립적으로 작성한 정확한 유리수 동적 계획법으로 확인했다. 다른 실패 문항의 참조 정답도 정수 모듈러 역원으로 별도 검산했다. 계산 코드와 문제·답 원문은 공개하지 않는다.

`2023-AIME-II-15` 재확인은 약 26.62초에 정답을 냈다. 사후 재확인 2회는 정답 1개·오답 1개였으며, 최초 결과의 시간 초과 2건을 지우거나 합계 58/60을 바꾸지 않았다. 전체 최초 60회와 사후 진단 2회를 구분하여 보관한다.

## 해석

- 일부 문항은 40~80초가 걸렸고 두 문항은 120초 내 최종 답을 받지 못했다. 최종 답 없는 대기의 원인을 이 계측만으로 추론·전송·공급자 내부 대기로 확정할 수 없다. 빠른 인사 응답과 복잡한 추론의 완료 시간을 구분해야 한다.
- 문항 표본 Wilson 95% 구간은 2024년 약 88.65~100%, 2023년 약 78.68~98.15%다. 공개 문제의 학습 포함 가능성이 있으며 모델의 반복 실행 안정성이나 모든 업무에 대한 구간이 아니다.
- 변경 전/후의 짝지은 비교가 아니므로 **성능 향상률을 주장하지 않는다.** 낮은 추론·다중 에이전트·다른 모델로 자동 전환하는 설정도 승격하지 않았다.
- AIME는 수학 정답 검사다. 도구 호출은 별도 [BFCL 실측](UPDATE_2026-10-02.md), 첨부·권한·UI는 별도 회귀 테스트로 구분한다. AI TOP 100 전체, 실제 GUI 업무, 취약점 탐색의 정확도 또는 공식 순위로 해석하지 않는다.
- 후속 후보는 격리된 정확한 계산 도구와 결과 검산을 결합하는 것이다. 단순히 추론을 높이거나 재시도를 늘리는 정책을 이 결과만으로 적용하지 않는다. 두 실패 사례는 개발 회귀 사례로 쓰되, 그에 맞춘 변경을 평가할 때는 별도 미사용 문제를 남겨야 한다.

## 증거와 공개 범위

로컬의 `release/validation/aime2024-sol6-auto-20261002.{manifest.json,progress.jsonl,report.json}`과 `aime2023-sol6-auto-20261002` 접두사 파일에 실행 설정·문항 ID·소스 해시·수치가 남아 있다. 각 실행 시작 시 기록한 소스 해시는 종료 시까지 동일했고, 두 실행 모두 30개 전체를 시도했다.

원본 report SHA-256은 2024년 `a7f5edb39c0f4346d880cc624e3fa548e3548312b3a532ac708243b9bb84dc6c`, 2023년 `eb54ae362024e227155431cee51dab049e54191934bb44e6d6a286415b7f544f`다.

캐시 원문·정답·개별 예측 정수·원시 로그는 Git에서 제외한다. Git에는 검사 코드, 합성 단위 테스트와 이 집계 보고서만 게시한다. 공식 리더보드 제출은 하지 않았다.

평가 관련 자동 테스트 53개와 평가 스크립트 TypeScript 검사, 데이터 준비 Python 구문 검사가 통과했다. 공개 소스·스테이지·Git 이력의 알려진 민감정보 패턴 검사도 통과했다. 이것이 모든 종류의 정보 노출이나 전체 앱 버그가 없음을 보장하지는 않는다.
