# Mr.Robot 0.6.16 작업 진행 화면과 배포 검증

PC와 모바일의 작업 상태를 같은 규칙으로 표시하고, 입력을 방해하던 작업 기록을 접을 수 있도록 정리했습니다. 실제 도구 실행, 승인 대기, 답변 수신, 중지 확인, 오류를 구분합니다. 모델의 비공개 추론이나 가상의 진행률을 생성해 보여주지 않습니다. 기존 공급자, 권한, 협업 프리셋과 대화 데이터는 변경하지 않습니다.

## 화면과 상태 처리

- PC 진행 카드를 얇은 상태줄로 정리했습니다. 경과 시간과 현재 활동이 보이고, 상세 기록은 입력창을 밀어내지 않는 펼침 패널에서 확인합니다.
- 모바일 작업 기록은 별도 하단 패널에서 확인합니다. 키보드가 열리거나 화면이 낮아져도 작업 기록을 열 수 있습니다. 메시지별 도구 목록은 기본적으로 접고, 원시 요청 자료 대신 도구명과 결과 상태를 표시합니다.
- Android 가로 입력 중에는 진행 상태를 도구줄의 버튼으로 압축해 중단 버튼이 키보드에 가려지지 않도록 했습니다. 키보드가 열렸을 때 제목이 시스템 상태표시줄과 겹치던 상단 여백도 수정했습니다.
- 진행 기록의 도구명, 완료·실패 판정과 시간 표시는 공용 코드로 묶었습니다. 완료 후 시간은 멈추고, 늦게 도착한 응답이 먼저 확인한 취소·오류를 완료로 덮어쓰지 않습니다.
- React의 반복 상태 검사에서 같은 도구 실행이 두 줄로 나타나던 변경 가능한 상태 갱신을 수정했습니다. 호출 식별자가 같은 시작 이벤트도 중복 표시하지 않습니다.
- 높이가 낮은 PC 창에서 입력 영역과 상단 정보를 줄여 대화에 더 많은 공간을 확보했습니다. 움직임 줄이기 설정에서는 진행 아이콘 애니메이션을 끕니다.
- 기존 사각형 중지 버튼, 추가 지시, 모델 검색, 공급자 필터와 캘린더 조작을 회귀 검사했습니다.

## 검증 결과

전체 `npm test`, 타입 검사, 웹 UI 실동작 검사, 원격 파일 보안 검사, 네이티브 화면 제어 검사와 실제 Electron 렌더러 복구 검사가 통과했습니다. 로컬 모의 모델 테스트는 고정 포트와 만료된 연결 재사용에 의존하지 않도록 격리했습니다. 실제 공급자 요청을 자동 재전송하도록 변경하지 않았습니다.

웹 화면은 7개 창 크기에서 프로젝트 생성·전환, 작업 기록 펼침, 추가 지시, 중지와 입력창 범위를 검사했습니다. 별도로 지연된 응답, 취소 확인 지연, 연결 상태 조회 실패 후 초안 복구, 모델 선택과 캘린더의 마지막 날짜 접근을 검사했습니다.

실제 앱의 인증된 요청 경로와 `gpt-6-sol`을 사용한 격리된 합성 대화 검사에서 120개 후속 응답의 기억이 일치했습니다. 연결이 끊긴 요청의 중복 실행 방지, 두 대화 중 한쪽만 취소, 앱 재시작 후 기억 유지도 통과했습니다. 이 연속 검사는 약 246초였으며, 수일간의 무중단 운영이나 일반 정답률을 입증하는 성능평가는 아닙니다.

플러그인 600회 재로딩과 WebSocket 80회 연결·해제 스트레스 검사에서 추적한 리소스가 기준으로 돌아왔습니다. 해당 검사에서 선형 메모리 누수 징후는 검출되지 않았지만 모든 운영 환경의 누수 부재를 보증하지 않습니다.

설치된 PC 앱에서도 0.6.16, 계산·기억·임시 파일 읽기, 기존 설정 유지와 활성 작업 종료를 확인했습니다. 렌더러 강제 종료 검사에서는 화면이 복구되고 에이전트 프로세스가 유지됐습니다.

## 모바일 패키지와 주의 사항

Android 버전은 0.6.16, versionCode는 44입니다. 릴리스 APK의 기존 서명 인증서와 현재 앱 소스 17개 모듈, 공용 소스 5개 모듈의 포함 여부를 확인했습니다. Android 에뮬레이터에서 실제 릴리스 APK의 설치·기동도 확인했습니다.

별도의 네이티브 UI 테스트 앱에서 실제 Android 키보드를 반복해서 열고 닫았습니다. 작업 실행 중인 화면을 세로·가로, 글자 크기 100%·150%의 네 조건으로 검사해 다중 행 입력 커서와 중단 버튼의 가림 검사가 통과했습니다. 세로 화면에서는 스트리밍 응답의 하단 따라가기도 검사했습니다. 이 테스트 앱은 같은 화면 컴포넌트와 모의 RPC를 사용하며, 실제 휴대폰이나 외부 원격망 테스트는 아닙니다.

실제 Android 휴대폰은 연결되지 않았습니다. 제조사별 키보드, 물리 기기에서의 파일 공유 및 LTE·외부 Cloudflare 경로 검증은 별도로 필요합니다. Windows 설치 파일은 Authenticode 서명되지 않아 SmartScreen 경고가 나올 수 있습니다. 데이터 폴더를 삭제하지 않고 기존 설치를 업데이트합니다.
