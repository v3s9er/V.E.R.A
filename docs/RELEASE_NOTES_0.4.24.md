# v0.4.24 — 첨부 분석 대상 분리 · 덮개/외부 화면 플러그인

## Discord 첨부가 섞이던 문제 수정

- 보관된 모든 파일을 매 질문에 넣던 동작을 제거했습니다. 새 첨부를 먼저 선택하고, 이후에는 파일 이름/종류 또는 티켓별 직전 분석 대상을 사용합니다.
- “내용 평문으로 다 출력”은 **선택한 파일의 전체 내용**을 의미합니다. 이전 PDF나 다른 녹음을 함께 분석하지 않습니다. 모든 보관 파일은 사용자가 명시적으로 요청했을 때만 선택합니다.
- 직전 분석 대상은 앱 재시작 후에도 같은 티켓·사용자·접근 권한 범위에서 유지됩니다. 이전 버전의 복구 기록 때문에 순서를 구분할 수 없으면 대상을 한 번 확인하며 재첨부를 요구하지 않습니다.
- 관계없는 일반 질문에는 첨부 목록·음성 인식 결과를 반복 주입하지 않아 입력 토큰과 대기 시간을 줄입니다.
- 관리자 네이티브 실행에는 선택된 파일만 임시 복사합니다. 격리 사용자의 첨부 목록/읽기/Python 첨부 지정도 이번 선택으로 제한합니다. 다른 티켓 접근 권한은 열지 않습니다.
- 응답에 분석 대상 파일을 표시하고, 음성 자동 인식 원문과 추정·교정 내용을 구분하도록 안내합니다. 음성 인식의 전문용어 정확도가 완벽해졌다는 의미는 아닙니다.
- 티켓 세션과 기존 대화·암호화 원본은 보존합니다. 이미 작성된 답변을 소급 삭제하거나 다시 쓰지 않습니다.

## 새 선택형 플러그인: 덮개 · 외부 화면

Windows 노트북에서 **플러그인 → 시스템 → 덮개 · 외부 화면 → 켜기**로 사용할 수 있습니다. 기본값은 꺼짐입니다.

- 덮개 열림을 확인한 뒤 닫으면 외부 디스플레이 출력 경로만 해제하고, 열면 이전 화면 배치를 복원합니다.
- ‘지금 화면 복구’, 감지 재시작, 상태/오류 표시를 제공합니다.
- 정상 종료·플러그인 해제·부모 프로세스 종료 시 복원을 시도하고, 비정상 전원 차단에 대비한 로컬 복구 구성을 저장합니다.
- 권한 승격, 서버, AI 호출, 유료 서비스, Discord 의존성은 없습니다. 명령은 로컬 관리자용이며 AI 도구로 노출하지 않습니다.
- 전원 계획을 변경하지 않으므로 Windows의 **덮개를 닫을 때: 아무것도 안 함** 설정을 유지해야 합니다. PC 앱이 실행 중이어야 합니다.
- 실제 케이블/USB 연결을 끊거나 모니터 전원을 제어하지 않습니다. HDMI/DP 오디오 출력은 함께 해제될 수 있습니다.
- 닫힌 내장 패널의 출력 경로를 허용하지 않는 드라이버, 원격 데스크톱 세션, 도킹 변경에서는 지원/배치 복원이 제한될 수 있습니다. 긴급 복구는 **덮개 열기 → Win+P → 확장**입니다.

## 검증 및 배포 범위

- 첨부 선택·티켓 유지·명시적 전체 선택·과거 파일 제외·다른 티켓 접근 거부·네이티브 임시 복사 회귀 테스트.
- 덮개 상태 제어의 중복 이벤트, 초기 닫힘, 수동 복구, 부분 실패/재시도, 이전 구성 복원 테스트.
- 플러그인 기본 비활성, 관리자 전용, 숨김 실행, 중복 프로세스 방지 및 종료/타이머 정리 테스트.
- 실제 Windows 환경에서 헬퍼 컴파일 및 읽기 전용 내장/외부 화면 진단. **실제 덮개를 물리적으로 닫고 여는 하드웨어 동작은 자동 검증하지 않았습니다.**
- PC 설치 마법사(EXE), 소스 ZIP 및 SHA-256 체크섬을 제공합니다.
- 모바일 코드는 변경하지 않았습니다. 기존 [v0.4.22 APK](https://github.com/v3s9er/Mr.Robot/releases/tag/v0.4.22)를 계속 사용하며, Discord 수정은 PC 호스트 업데이트로 적용됩니다.

개인 첨부·대화·토큰·복구 구성은 배포에 포함하지 않습니다. Discord 자체는 E2EE 채널이 아니며, 선택한 첨부의 인식 결과는 사용 중인 AI 공급자에게 전달될 수 있습니다.
