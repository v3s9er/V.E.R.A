# V.E.R.A 0.7.6

## Discord 관리자 지정 모델

- 서버 관리자가 `/robot-admin model user:@사용자`에서 공급자·모델·추론 강도를 선택하고 **저장**합니다. 해당 서버에서 그 사용자의 기존·새 티켓에 적용하며 PC 접근 권한은 바꾸지 않습니다.
- 일반 이용자의 모델 선택 버튼, 공급자·모델 목록 명령, `/robot ask` 모델·추론 옵션을 제거했습니다. 상태 메시지에도 관리자 설정을 노출하지 않습니다. 관리 메뉴는 관리자에게만 기본 표시되며, 예전 버튼과 직접 요청도 현재 관리자 권한을 다시 검사합니다.
- 기존 모델 상한과 사용자 지정 티켓 설정은 보관하되 더 이상 실행에 사용하지 않습니다. 명시적 지정이 없으면 PC 기본 공급자·모델과 자동 추론을 사용합니다. **PC 기본값으로** 버튼으로 이 상태를 복원할 수 있습니다.
- 모델은 현재 연결 계정의 사용 가능한 목록에서 선택합니다. 저장·실행 시 지원 추론 단계와 정확한 공급자·모델을 확인하고, 다른 모델로 조용히 대체하지 않습니다. 대상 사용자가 작업 중이면 중지 후 설정할 수 있습니다.
- 재연결 시 등록된 열린 티켓 최대 64개에서 최근 100개 메시지를 확인해 봇이 작성한 예전 모델 선택 버튼을 새 작업 제어 메뉴로 교체합니다. 본문·첨부·대화 기록은 삭제하지 않습니다. 더 오래된 버튼이 남아도 일반 이용자는 변경할 수 없습니다.

## Discord 직접 단일 모델 실행

PC의 라우팅 프리셋을 상속하지 않는 기존 동작을 유지하고, 관리자 실행에도 V.E.R.A 자체 보조 에이전트와 다른 도구 실행 모델로의 인계를 차단했습니다. 관리자 지정 모델에 요청을 전달하며 티켓별 세션 재사용, 스트리밍, 취소와 권한·첨부 검증은 유지합니다. **구독 CLI 자체의 하위 에이전트 기능은 이번 변경으로 제한하지 않습니다.** 단일 모델은 한 번의 호출만 의미하지 않으며 도구 결과를 받기 위한 추가 턴은 가능합니다.

## 검증 및 배포 범위

모의 Discord 명령 등록·관리자 재검증·선택창·이전 버튼 정리, 사용자별 지정과 비관리자 우회 차단, 실제 에이전트 루프의 API/네이티브 호출 직전 모델 검사, Discord 직접 실행과 일반 앱의 오케스트레이션 유지, 티켓·첨부·격리·암호화 파일 전송 회귀 검사를 포함합니다. 모델 응답을 모의한 기능 검사이며 AI 성능 측정 결과가 아닙니다.

Windows 데스크톱과 PC 에이전트 업데이트입니다. APK는 새로 배포하지 않으며 공개 Android APK는 0.7.2(versionCode 48)를 유지합니다. 모바일 소스 버전은 0.7.6으로 동기화하고 다음 APK 배포 전에 versionCode를 올려야 합니다. 기존 설치 ID·프로필·대화·페어링, MIT 라이선스 및 제3자 고지는 유지합니다. Windows 설치 파일은 미서명입니다.
