# V.E.R.A 0.8.0 — 단일 에이전트 하네스

선택한 모델 하나가 작업을 끝까지 이어가도록 실행 구조를 정리했습니다. 기존 다중 모델 프리셋은 읽기 전용 기록으로 보존하며 실행하지 않습니다. API·네이티브 보조 에이전트와 자동 대체 모델을 사용하지 않고, 실제 실행별 토큰 예산 검사는 유지합니다.

## 변경

- 프로젝트별 선택 문서 검색, 출처·해시·발췌, 내용 변경에 따른 캐시 갱신.
- 지식 후보 → 사용자 확인 → 재사용 → 철회. 오래되거나 충돌한 근거는 그대로 확정 사실로 사용하지 않음.
- 실제 명령/산출물 검증 프로필과 결과 화면. 검증 프로필의 명령·실행 동의는 모델이 수정할 수 없음.
- 실패한 작업 온톨로지 파일 조건은 같은 에이전트가 최대 1회 후속 수정.
- Codex 세션·warm process 재사용 유지, 정책 변경에 따른 이전 세션 분리, 취소 시 프로세스 종료 확인.
- 단일 하네스 UI와 기존 프리셋 보관 표시, 설치된 Context7·Serena 경로 불러오기.
- Discord의 관리자 지정 모델·추론·사용자 권한 보존. 명시한 추론 강도를 간단한 질문이라고 낮추지 않음.
- 저장된 이전 프리셋이 선택한 모델을 가리거나 삭제된 프리셋 때문에 실행이 막히던 경로 제거.
- 잘못된 대화 생성·수정 메타데이터를 저장 전에 거부하여 재시작 시 정상 대화가 손상된 저장소로 분류되지 않도록 보완.

## 범위

ARTEX 코드·패키지·프로토콜은 결합하지 않았습니다. 새 호스트 하네스 도구는 Codex native 및 API 경로에서 지원합니다. Claude native의 동적 호스트 연결, 임베딩 검색, 모델 가중치 학습, 무인 지식 승인/배포는 이번 구현에 포함되지 않습니다. 폴더 제한 검증 명령은 실제 샌드박스 adapter가 없으면 실행하지 않습니다. PC/웹 설정 화면은 작은 화면도 지원하지만 Android 네이티브 설정 화면은 별도입니다. 모바일 소스에서는 단일 하네스 표시와 이전 프리셋 보존을 반영했으며 이 릴리스의 설치 파일은 Windows용입니다.

검증은 기능·회귀 테스트입니다. 실제 모델의 종합 정확도 향상이나 단독 Codex/Claude 대비 우위를 입증한 벤치마크 결과가 아닙니다. 상세 동작과 한계는 [설계 문서](single-agent-harness.md), 실행한 검사와 한계는 [검증 기록](VALIDATION_0.8.0.md)을 참고하세요.

기존 설치 식별자·사용자 프로필·페어링·MIT 라이선스는 유지합니다. 사용자 정보, 문서 원문, 지식 상태, 자격증명, 설치된 외부 도구는 공개 Git에 포함하지 않습니다.
