# 0.6.6 — 이미지 증거 전달과 불확실성 처리

- Code Mode에서 원본과 확대본 사이의 설명까지 이미지 URL에 붙이던 잘못된
  사용 예제를 수정했다. 모든 이미지와 설명을 순서대로 분리해 표시한다.
- 이미지 개수와 순서를 결과 메타데이터에 명시하고, 사용 예제 자체를
  단일/복수 이미지 및 오류 응답으로 실행하는 회귀 검사를 추가했다.
- 두 로컬 OCR 판독이 다른 문자는 정답처럼 합치지 않는다. 기본 출력에서
  불확실 영역으로 표시하고 해당 원본 픽셀을 제공한다. 원시 후보 두 개는
  `ocrHypotheses:true`로 명시적으로 비교할 수 있다. OCR은 여전히 미검증 자료다.
- 사용자 데이터와 분리한 네이티브 창 복구 테스트가 실행 중인 앱과 포트로
  충돌하지 않도록 테스트 인스턴스에 임시 loopback 포트를 할당했다.
- 0.6.5의 쉬운 요청 경량 경로, 선택 모델 보존, 어려운 작업의 추론 설정,
  세션 기억 및 취소 동작을 유지한다. 권한 경계는 완화하지 않았다.
- 직전의 짧은 단순 답변을 명시적으로 다시 보여 달라는 요청도 대화 기록을
  유지한 채 도구 없는 경량 경로로 처리한다. 맥락 없는 "다시 해", 실제 작업의
  재실행, 복잡한 이전 요청, 긴 답변이나 도구 호출 이력에는 이 규칙을 적용하지
  않는다. 후속 실제 작업은 선택한 추론 강도와 기존 권한으로 돌아간다.

측정과 제한은 [검증 기록](OBSERVATION_0.6.6_2026-10-03.md)을 참조한다.
