# Mr.Robot 0.4.7 — Discord 개인 스레드 작업실

0.4.6의 질문별 예산·Discord 관리자 권한 개선을 포함합니다.

## 사용 방법

1. PC 플러그인의 **ai_talk 티켓 패널 설치**를 누르거나 원하는 텍스트 채널에서 서버 관리자가 `/robot bind`를 한 번 실행합니다. 새로 생성한 ai_talk 채널은 관리자와 봇만 보도록 설정합니다. 기존 채널의 권한은 덮어쓰지 않습니다.
2. 고정된 패널의 **티켓 열기**를 눌러 제목을 입력해 요청하면 비공개 개인 스레드를 만듭니다. 접속만으로 자동 생성하지 않습니다.
3. 스레드에서 일반 메시지로 작업을 요청합니다. 봇·웹훅·다른 사용자의 메시지는 실행하지 않습니다.
4. **모델·권한 설정**, **작업 중지**, **보관**, **삭제** 버튼을 사용합니다. `/robot sessions` 또는 부모 채널의 **내 티켓 목록**에서 다시 엽니다.
5. `/robot unbind`는 연결만 해제합니다. 스레드나 PC 기록을 자동 삭제하지 않습니다.

## 세션과 실행

- 등록 서버당 부모 채널 하나, 사용자별 최대 20개/전체 64개 세션. 토큰 제한이 아닌 저장소 보호입니다.
- 스레드·소유자·PC 대화 연결·모델·추론·권한은 로컬 플러그인 저장소에 유지되어 재시작 후 복구됩니다.
- Discord는 앱 토큰 제한 없이 실행합니다. 공급자 사용 한도와 요금은 유지됩니다.
- 일반 메시지는 PC의 단일 Discord 실행 경로로 순서대로 처리합니다. 대기열은 전체 16개/스레드 4개이며 작업 중지는 해당 스레드의 대기 요청도 취소합니다. 추가 메시지는 진행 중 작업에 끼워넣는 것이 아니라 후속 작업입니다.
- 삭제는 사용자 확인 후 Discord 스레드와 메시지를 영구 삭제합니다. PC의 기존 대화 기록은 남습니다. 실행 중인 스레드는 먼저 작업을 중지해야 보관·삭제할 수 있습니다.
- 첨부 파일은 아직 일반 메시지 실행 입력으로 전달하지 않습니다. 첨부가 있으면 명시적으로 안내하고 실행하지 않습니다.

## 권한과 운영

- 매 요청 및 실행 중 서버 Administrator 권한을 다시 확인합니다. 관리자라도 다른 사용자의 세션 실행·결과·승인·설정·삭제는 불가합니다.
- 비공개 스레드도 Discord의 Manage Threads 권한자는 볼 수 있습니다. 비공개를 종단간 암호화나 관리자에게도 숨기는 기능으로 표현하지 않습니다.
- 봇에는 채널 보기·메시지 보내기·기록 보기·비공개 스레드 생성·스레드 메시지·스레드 관리 권한이 필요합니다. 고정 권한이 없으면 패널을 게시하고 고정 불가를 안내합니다.
- 일반 메시지 수신은 Developer Portal → Bot → Message Content Intent가 필요합니다. 비활성 상태에서는 slash 명령은 유지하고 일반 채팅 불가를 안내합니다. 실행 시 임의로 모든 privileged intent를 요청하지 않습니다.
- 봇 토큰, 서버/사용자/채널 ID, 개인 스레드 상태, PC 자격증명은 공개 소스나 설치본에 포함하지 않습니다.
- 새 APK 릴리스는 포함하지 않습니다. Android의 Discord 앱에서도 동일한 스레드 UI를 이용할 수 있습니다.

## 검증 범위

호스트 세션 소유권·재시작 저장·연결/해제·보관/복구·삭제 정리, Python 관리자 검사·봇/웹훅 무시·대기열·확인 버튼·persistent view 회귀 테스트를 추가했습니다. 기존 질문 예산/Discord 권한/PC·모바일 타입 검사와 핵심 회귀도 함께 확인합니다.
