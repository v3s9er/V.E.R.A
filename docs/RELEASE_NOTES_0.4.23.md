# Mr.Robot 0.4.23 — Discord 첨부와 티켓 대화 복구

- 티켓이 이미 삭제된 PC 대화 ID를 사용하는 경우, 후속 질문마다 새 대화가 생기던 문제를 수정했습니다. 같은 티켓·접근 범위의 첨부 원본도 새 바인딩으로 이어집니다.
- 일반 사용자와 관리자 접근 범위의 대화·파일 격리는 유지합니다. 서로 다른 접근 범위의 기록을 자동으로 합치지 않습니다.
- PC 네이티브 앱 대화 목록을 **내 대화 / Discord** 공간으로 분리했습니다. 기존 기록은 삭제하지 않으며, 알려진 이전 Discord 기록도 별도 공간에 표시합니다.
- 사용자 말풍선·제목에 내부 첨부 목록이 길게 노출되지 않도록 정리했습니다. 모델에 전달하는 원본 문맥은 보존합니다.
- 대화 공간을 바꾸는 동안 도착한 이전 요청의 응답·정지 상태·승인 창이 다른 대화에 섞이지 않도록 했습니다.
- 최소화된 PC 앱을 트레이나 바로가기로 다시 열 때 창이 복원되도록 했습니다.
- WAV 등 음성 첨부에 로컬 음성 인식을 추가했습니다. 최초 1회 공개 엔진·모델을 준비한 뒤 외부 통신 없는 컨테이너에서 인식합니다. 긴 음성은 구간별로 이어 읽을 수 있습니다.
- 관리자용 네이티브 CLI에 존재하지 않는 `/work` 경로 대신 실제 첨부 임시 복사본 경로를 전달합니다. 작업 종료·중지 시 임시 복사본을 정리합니다.
- 음성 인식 결과는 티켓별 제한된 메모리 캐시에 저장합니다. 파일 소유권·암호화 무결성·만료 검사는 캐시 조회 전에도 수행합니다.

이번 변경의 PC 호스트 기능은 기존 모바일 클라이언트에서도 이용됩니다. 모바일 앱 자체의 UI 변경이나 새 APK는 포함하지 않습니다. 모바일 설치파일은 [v0.4.22 릴리스](https://github.com/v3s9er/Mr.Robot/releases/tag/v0.4.22)의 APK를 사용하세요.

검증: 타입 검사, Discord 권한·격리·세션 및 첨부 회귀 테스트, 대화 공간·창 복원 테스트, 실제 음성 원본 읽기, PC 앱 탭 전환을 확인했습니다. 소스·Git 기록과 배포 설치파일의 민감정보 검사를 통과했습니다.

보안 범위: Discord 자체의 종단간 암호화를 의미하지 않습니다. 음성 자동 인식은 로컬에서 수행하지만, 분석 결과는 사용자가 선택한 AI 공급자에게 질문 문맥으로 전달될 수 있습니다.
