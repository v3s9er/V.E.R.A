# V.E.R.A 0.7.0

2026-10-04. 소스 변경 내역입니다. 바이너리 게시와 설치 여부는 GitHub Releases 및 설치본 버전을 별도로 확인하세요.

## 이름과 설치 호환성

데스크톱 창·트레이·웹·모바일·기본 플러그인의 제품 표시를 V.E.R.A로 통일했습니다. 새 배포 파일도 V.E.R.A 이름을 사용합니다. 기존 MIT 라이선스와 의존성별 저작권 고지는 유지하며 외부 에이전트 코드를 가져오지 않았습니다.

기존 사용자의 대화, 암호화 데이터, 페어링을 보존하기 위해 실행 파일 `Mr.Robot.exe`, Windows 설치 ID, Android 앱 ID, npm 이름, `~/.mr-robot`, Electron 프로필, 프로토콜의 내부 식별자는 변경하지 않습니다. 표시 이름을 바꾸기 전에 Electron의 기존 프로필을 고정하며, 명시적인 테스트 프로필도 존중합니다. 기존 데이터를 새 폴더로 복사하거나 초기화하지 않습니다.

## 협업과 검색 정확성

- 동일 부모 작업에서 동일 `assignmentKey`와 작업·맥락·작업자 조합을 재전송하면 진행 중인 하위 작업을 재사용합니다. 키를 생략하거나 다른 키를 쓰면 독립적인 검토를 그대로 실행합니다. 서로 다른 지시를 같은 키로 덮어쓰지 않습니다.
- 특정 하위 작업만 기다릴 때 다른 작업의 아직 읽지 않은 결과가 전역 커서 때문에 사라지던 문제를 수정했습니다. 같은 결과 본문은 이미 전달됐으면 반복 주입하지 않습니다.
- 작업 대기는 기본 30초·최대 60초의 이벤트 기반 대기로 조정했습니다. 결과·상태 변경·취소가 오면 즉시 깨어나며, 네이티브 연결의 시간 제한도 그보다 길게 맞췄습니다. 변화가 없는데 모델을 15초마다 다시 호출하는 낭비를 줄입니다.
- 온톨로지 검색이 최신 2,048개 기록에 먼저 잘려 오래된 관련 관계·충돌을 놓치던 문제를 수정했습니다. 범위 안의 관련 사실을 색인으로 찾고, 실제 관계 연결·추론·프롬프트 크기는 계속 제한합니다. 최신 주장이라는 이유만으로 모순을 해소하지 않습니다.
- 메모리 변경 시 무효화되는 범위별 불변 색인을 재사용합니다. 최대 8개 범위·40,000개 기록·추정 32MiB를 유지하며 대화/프로젝트 범위를 섞지 않습니다. 임시 관찰은 작은 별도 색인으로 합치고 결과를 영속 캐시하지 않아, 프로젝트 관측 때마다 전체 색인을 재구축하지 않습니다. 중복 ID는 기존 재구축 동작을 유지합니다.
- 첫 추론 경로가 순환에 걸리면 독립적인 정상 경로도 미확정으로 남던 문제를 수정했습니다. 반대로 일부 순환 경로가 정상 근거로 남던 경우도 차단합니다. 최대 두 번의 제한된 폐쇄 계산만 사용하고 충돌·누락을 정상 사실로 바꾸지 않습니다.

## 실제 모델별 추론 선택

Codex `model/list`가 반환한 모델별 추론 단계와 기본값을 보존합니다. PC·모바일·Discord는 선택한 모델의 값만 표시하며, `ultra`도 실제 지원이 확인된 모델에서만 활성화됩니다. 지원 정보가 없으면 자동만 제공하고 명시적 미지원 요청은 실행 전에 설명합니다. 모델을 바꾼 어댑터도 기존 제공자의 목록 캐시를 공유해 매 질문마다 새 CLI 조회를 만들지 않습니다. Daybreak는 모델 선택과 별개의 기존 옵션을 유지합니다.

단일 요청은 선택한 제공자의 정보만 준비합니다. 관계없는 Codex 제공자의 느린 목록 조회가 기본 API 요청까지 지연시키지 않으며, 취소 시 해당 요청의 대기를 즉시 끝냅니다. 비용 등급 조회는 전체 모델 목록을 복사하지 않습니다.

## 진행 화면

PC와 모바일에서 선택한 실행 정책과 실제 관측된 하위 작업을 구분합니다. 협업이 선택됐다는 이유만으로 에이전트 여러 개가 실행 중이라고 표시하지 않습니다. 도구·작업자의 대기, 실행, 완료, 실패, 취소를 제한된 목록으로 표시하고, 원시 JSON이나 모델의 비공개 추론을 진행 로그로 노출하지 않습니다. 검증 시작과 검증 성공도 구분합니다. 최근 32개 내역에서 밀려난 이전 오류도 경고를 유지하며, 일부만 표시된 내역을 전체 정상 이력처럼 표현하지 않습니다.

## 평가 원칙

새 `benchmark:app`은 실제 데스크톱 번들의 인증된 `chat.start` 경로를 사용합니다. 별도 시험 프로필·프로젝트·대화를 만들며 기존 사용자 설정을 복사하거나 수정하지 않습니다. 같은 모델·추론 강도·문제·시간 제한으로 단일 실행과 적응형 협업을 비교합니다. 데이터와 실행 파일의 해시를 고정하고, 실패·누락·알 수 없는 토큰량을 숨기지 않습니다.

모델 추론 전 승인 대기로 끝난 초기 시험은 실력 점수에서 제외하고 시험 설정 실패로 기록했습니다. 시험용 폴더 권한을 명시하고 실제 적용 권한을 사전 확인하는 회귀 검사를 추가합니다. 자세한 절차와 공개 문제 사용상의 한계는 [평가 프로토콜](VERA_EVALUATION_PROTOCOL.md)을 따릅니다.

검색 회귀 검사에서 10,000개 기록의 오래된 근거·충돌을 새 구현이 보존했고 기존 최신 2,048개 제한은 누락했습니다. 별도로 같은 검색 규칙을 고정한 `MemoryStore.retainedContext(observed)` 실측에서는, 매번 저장 색인을 재구축하던 중간 구현 대비 최종 재사용 구현의 중앙값이 10,000개 기록에서 **48.150ms → 0.226ms**였습니다. 최초 생성은 **45.963ms**로 여전히 비용이 있습니다. 규모별 20개 고유 조회를 적중/미적중 교대로 실행했고 사실·충돌·문맥은 전부 일치했습니다. 보고서 SHA-256: `227354b5c76c0b8a95bc57ddba8c76fdee9d9510fcfcd8ca137ac79d4b0cbc56`.

이는 **정확성 수정 전의 원래 버전과 직접 비교한 전체 속도 배율도, AI 응답 시간·정답률 개선도 아닙니다.** Unicode 부분문자열 검색 등은 여전히 전체 탐색이 필요하며 실제 모델 추론 시간은 별도 평가합니다. 소스·데이터·쿼리와 측정 반복을 고정한 상세 기록은 로컬 평가 보고서에 보관합니다.

현재 자료로 세계 최고 수준을 주장하지 않습니다. 공개 AIME는 수학 추론 한 영역이며 사전 학습 오염 가능성이 있습니다. 합성 관계 문제는 온톨로지 기능 검사이고, 실제 개발·검색·GUI 수행 능력은 별도 검증이 필요합니다.
