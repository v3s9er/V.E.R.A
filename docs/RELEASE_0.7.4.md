# V.E.R.A 0.7.4

## 일반 대화는 바로, 프로젝트만 폴더로

- 프로젝트에 속하지 않은 대화를 감싸던 **일반 대화** 폴더를 제거했습니다. 일반 대화는 사이드바 목록에 바로 표시하고 실제 프로젝트만 접기·펼치기 가능한 폴더로 유지합니다.
- 일반 대화에는 폴더 들여쓰기나 최근 5개 제한을 적용하지 않습니다. 이전 버전에서 일반 대화 폴더를 접어둔 설정이 남아 있어도 대화를 숨기지 않으며, 검색은 실제 대화 제목을 기준으로 합니다.
- 프로젝트 연결이 해제된 대화도 일반 대화 목록에서 계속 찾을 수 있습니다. 목록 표시 방식만 바꾸며 기존 대화나 작업 폴더를 삭제·이동하지 않습니다.
- 프로젝트별 목록, 검색, 대화 고정·실행 상태, 보관함과 별도 Discord 공간은 유지합니다.

## 검증 및 배포 범위

프로덕션 빌드, 웹 타입 검사, 버전 정합성 및 반응형 UI 계약 검사를 통과했습니다. 사이드바·대화 전환·실행 화면 회귀 검사는 1280px, 992px의 낮은 창, 390px 화면에서 통과했습니다. 일반 대화의 직접 표시, 오래된 접힘 설정, 검색, 프로젝트 폴더, 고정·실행 상태와 Discord 분리를 확인했으며 사용자 데이터·모델 계정을 사용하지 않는 격리된 모의 RPC 검사입니다. AI 성능 향상을 측정한 결과는 아닙니다.

Windows 데스크톱과 PC 에이전트의 웹 화면만 업데이트합니다. 모바일 브라우저는 새 웹 화면을 사용하지만 별도 React Native Android 앱의 새 APK는 빌드·배포하지 않습니다. 기존 공개 Android 0.7.2 APK(versionCode 48)는 그대로 유지합니다. 소스 버전 표시는 0.7.4로 동기화하되 Android `versionCode`는 48로 유지하며 다음 APK 배포 전에 올려야 합니다.

기존 설치 ID, 사용자 프로필, 대화·프로젝트·페어링, MIT 라이선스와 제3자 고지는 유지합니다. Windows 설치 파일은 코드 서명 인증서 없이 빌드됩니다.
