# Mr.Robot 0.4 빠른 사용 가이드

## 1. PC에서 바로 시작

Windows 설치 파일을 실행한 뒤 Mr.Robot을 켜면 PC 앱은 다른 기기를 연결하지 않아도 단독으로 동작합니다. 처음 한 번만 외부 도구 검사가 열리며, 설치된 항목은 건드리지 않고 누락된 선택 항목만 설치할 수 있습니다. Codex CLI와 Claude Code의 로그인은 각 공식 로그인 화면에서 직접 진행합니다.

대화 상단에서 다음 항목을 대화마다 따로 저장할 수 있습니다.

- **시나리오**: `단일 모델` 또는 저장된 복합 트리
- **모델**: 시나리오 자동 배정 또는 특정 제공자·모델
- **컨텍스트**: 입력창 하단의 모델별 추론 강도, 작업 폴더, 액세스 권한
- **대화 관리**: 고정, 이름 변경, 보관, 복원, 삭제

작업 폴더가 필요하면 컨텍스트 패널의 `폴더 추가`를 누릅니다. 데스크톱 앱에서는 Windows 폴더 선택기가 열리고, 원격으로 연결한 기기에서는 PC 관리자가 미리 등록한 폴더만 선택할 수 있습니다.

## 2. 단일 모델과 복합 시나리오

`단일 모델`은 선택한 Codex·Claude·API 모델을 한 개의 네이티브 에이전트 실행 경로로 사용합니다. 대화 기록, 작업 폴더, 권한, 도구 승인, 취소·끼워넣기, 파일 첨부는 Mr.Robot이 공통으로 관리합니다.

복합 시나리오는 필요한 경우에만 여러 모델 호출을 사용합니다. 기본 제공 프리셋은 삭제하거나 덮어쓸 수 없으며, 복사해 만든 사용자 프리셋은 자유롭게 수정할 수 있습니다.

- **Mr.Robot 스마트 캐스케이드**: 저비용 모델부터 시작하고 검증이 부족할 때만 상위 모델 사용
- **저비용·고효율 투표**: 여러 후보가 짧게 독립 검토한 뒤 결과를 투표·검증
- **순차 실행·검증**: 실행자 결과를 별도 검증 노드가 확인하고 필요할 때만 재작업
- **분류·회의·검증 혼합**: 요청 분류, 그룹 토론, 그룹 간 의견 교환, 최종 검증 조합
- **CTF 경쟁 스웜**: 격리된 Docker 작업공간에서 여러 해결자가 정보를 공유하며 제한 횟수 안에서 경쟁

동일 파일과 긴 문서는 컨텍스트 브로커가 한 번 읽어 정규화한 뒤 해시 기반 캐시로 재사용합니다. OpenAI·Anthropic의 공급자 캐시 사용량도 수집하며, 설정의 사용량 화면에서 입력·출력·추론·캐시 재사용 토큰을 확인할 수 있습니다.

## 3. 모바일 연결

모바일 APK를 설치하고 PC 앱의 `설정 → 모바일·기기 연결`에서 PIN 또는 QR을 사용합니다. PIN은 관리자 비밀키가 아니라 폐기 가능한 기기별 토큰을 발급합니다. 새 연결은 기본적으로 `변경 전 확인` 이하 권한이며, 더 높은 권한은 PC 앱에서 해당 기기를 직접 승격해야 합니다.

QR 스캐너는 코드를 읽자마자 연결하지 않습니다. 유효한 Mr.Robot QR을 인식하면 카메라를 멈추고 QR에 들어 있는 모든 접속 후보를 보여 줍니다. 내용을 확인한 뒤 **인식한 PC에 연결**을 눌러야 PIN 교환과 저장이 시작됩니다. 다른 QR을 비춰도 스캐너는 계속 동작하며, **다시 스캔**으로 인식 후보를 버릴 수 있습니다.

평문 HTTP 주소는 인증정보 노출을 막기 위해 원격 앱에서 사용할 수 없습니다. 휴대폰 VPN 없이 쓰려면 PC 플러그인에서 Cloudflare Quick Link 또는 고정 Tunnel을 시작하고 표시된 HTTPS 주소/QR을 등록하세요. Tailscale을 쓰는 경우에도 숫자형 `100.64.0.0/10` 주소가 아니라 Tailscale Serve가 제공하는 HTTPS 이름을 사용합니다. 주소 대역만으로 실제 Tailscale 라우트를 증명할 수 없기 때문입니다.

모바일 채팅 입력창은 키보드의 실제 상단 좌표와 입력 카드의 화면 좌표를 다시 측정해, 운영체제가 화면 크기 조절을 누락한 경우에도 겹친 높이만큼 올라옵니다. 여러 줄 입력 중에도 현재 커서와 전송 버튼을 키보드 위에 유지하고, 키보드가 열린 동안 하단 탭을 숨겨 입력 영역을 확보합니다. 다른 대화를 보고 있어도 실행 중인 대화별 상태가 분리되며, 실행 중지와 추가 지시가 원래 작업에만 전달됩니다.

입력창 안의 **권한**과 **추론** 드롭다운은 현재 대화에 저장됩니다. 권한은 읽기 전용·변경 전 확인·작업 폴더 자동·전체 허용 중에서 고르되, PC가 이 휴대폰에 부여한 기기 상한보다 높은 단계는 잠깁니다. 반복 승인을 줄이려면 PC의 `설정 → 권한 및 안전 → 원격 PC 관리`에서 해당 휴대폰 상한을 한 번 `작업 폴더 자동`으로 올린 뒤 모바일 입력창에서 같은 단계를 선택하세요. 모바일만으로 상한을 올릴 수 없고 `전체 허용`은 명시적으로 필요한 경우에만 PC에서 허용해야 합니다.

**추론** 드롭다운은 현재 선택한 Codex·Claude·API 제공자가 지원하는 단계만 보여 줍니다. `자동`은 항상 선택할 수 있고, 모델 또는 프리셋을 바꿨을 때 기존 단계가 새 제공자에서 지원되지 않으면 자동으로 `자동`으로 돌아갑니다.

## 4. VPN 없이 외부에서 연결

Tailscale은 선택 플러그인입니다. 금융 앱 때문에 휴대폰 VPN을 계속 켜기 불편하면 다음 흐름을 사용합니다.

임시 연결은 PC 앱의 `플러그인 → Cloudflare Remote Link`에서 **Quick Tunnel**을 선택하고 `빠른 연결`을 누릅니다. cloudflared가 없으면 첫 실행 의존성 마법사 v5, 플러그인의 `cloudflared 설치` 버튼, 또는 첫 Quick Link 승인 중 하나가 Windows winget의 x64 사용자 범위 portable 패키지로 설치합니다. 설치에는 몇 분이 걸릴 수 있으며 앱은 완료까지 연결 버튼을 정상 대기 상태로 유지합니다. 외부 연결 검사가 끝난 뒤 **10분·1회용 외출 코드 생성**을 명시적으로 눌러 12자리 코드가 든 HTTPS QR을 만든 다음 모바일에 등록합니다. 공개 Cloudflare 주소에서는 일반 6자리 PIN을 받지 않습니다.

주소를 계속 유지하려면 같은 화면에서 **Cloudflare 고정 Tunnel**을 선택합니다.

1. Cloudflare Networking → Tunnels에서 remotely-managed Tunnel을 만듭니다.
2. Public Hostname을 `pc1.example.com`처럼 등록합니다. 앱은 실행 때 그 호스트 → 표시된 loopback Agent 한 경로와 catch-all 404를 로컬에서 강제합니다.
3. Zero Trust → Access → Applications에서 정확한 호스트의 Self-hosted 앱을 만듭니다.
4. 본인 이메일 하나만 포함하는 Allow 정책과, 정확한 Service Token 하나만 포함하는 Service Auth 정책을 추가합니다. Bypass·Everyone·Any Access Service Token은 사용하지 않습니다.
5. 플러그인에 고정 호스트명, Tunnel Connector 토큰, Access Client ID/Secret을 입력합니다. 두 번째 PC 주소를 직접 가져올 때는 같은 도메인의 정확한 주소만 `PC 간 전송 허용 호스트`에 추가합니다.
6. 저장한 뒤 `고정 Tunnel 연결`을 누릅니다. 앱은 익명 요청 차단과 Service Token 통과를 모두 확인하지 못하면 Tunnel을 즉시 중지합니다.
7. 새 휴대폰을 등록할 때만 10분·1회용 코드를 만든 뒤 **보안 QR 60초 표시**를 눌러 휴대폰에 직접 스캔합니다. QR에는 주소·1회용 코드·5분 이하의 서버 결합 등록권만 들어가며 장기 Access Client ID/Secret은 포함되지 않습니다. 스캔하면 서버가 한 번만 장기 자격을 전달하고 앱이 Android 보안 저장소에 원자적으로 저장합니다. 보호 검증이 끝난 뒤에만 `Mr.Robot 시작 시 자동 연결`을 켭니다.
8. 이 계정에 다른 공개 호스트가 없을 때만 Access settings의 account-wide default deny를 켭니다. Log Explorer와 유료 Workers·R2·Images·Stream은 연결 경로에 추가하지 않습니다.

두 Cloudflare 방식 모두 휴대폰 VPN 없이 HTTPS/WSS로 연결합니다. 인증된 앱은 HTTPS에서 30초·1회용 WebSocket 업그레이드 티켓을 자동으로 받아 연결하므로 별도 입력은 필요 없습니다. Quick 주소는 재시작할 때 바뀌지만 고정 Tunnel은 사용자 도메인을 유지합니다. Tunnel 토큰과 Access 자격증명은 Windows DPAPI로 암호화되고, Android에서는 SecureStore/Keystore에 저장됩니다. Access 자격증명은 등록한 정확한 HTTPS origin 하나에 묶이므로 이후 발견한 LAN·Tailscale·유사 주소에는 전송되지 않습니다. Tunnel 토큰과 Access Service Token은 상태·QR·로그·명령줄·renderer RPC에 반환되지 않습니다. 고정 Tunnel 보안 QR은 명시적 승인 뒤 60초만 주소·1회용 코드·최대 5분의 서버 결합 assertion을 표시합니다. 모바일은 등록이 성공한 한 번에만 장기 Access 자격을 받아 Keystore에 저장하므로 사용자가 직접 입력할 필요가 없습니다. 대시보드에 다른 origin 경로가 남아 있어도 Connector는 앱이 만든 단일 Agent ingress와 404 catch-all만 실행합니다. 자동 연결은 PC와 Mr.Robot이 실행 중일 때만 유효합니다.

일반 브라우저에서는 다른 로컬 웹 화면에 Service Token을 입력하지 말고 보호된 원격 주소를 직접 열어 Cloudflare Access로 로그인하세요. 브라우저 원격 사용은 같은-origin 로그인 세션만 지원하며, 교차-origin Service Token 연결은 자격증명 유출 방지를 위해 지원하지 않습니다. Android 파일 업로드·다운로드는 리디렉션을 따라가지 않는 네이티브 스트리밍 경로를 사용합니다.

외출 전에 새 휴대폰을 등록해야 한다면, 원격 링크가 실행 중인 상태에서 PC 관리자로 **10분·1회용 외출 코드 생성**을 누릅니다. 이 12자리 코드는 PC에 저장되지 않고 실행 중인 Agent 메모리에만 있으며, 모바일의 PIN 입력란에 Quick Link 주소와 함께 입력할 수 있습니다. 한 기기가 연결하면 즉시 폐기되고 일반 6자리 PIN도 함께 바뀝니다. 반대로 일반 PIN 사용·재생성, 링크 중지, 앱/Agent 재시작, 또는 **즉시 폐기**도 외출 코드를 무효화합니다. 따라서 외출 중 연결하려면 PC와 Mr.Robot 및 cloudflared를 켜 둬야 하며, 코드는 비공개 저장소에만 보관하세요.

Tailscale을 선호하면 플러그인에서 켠 뒤 PC·모바일을 같은 계정에 연결하고, PC의 로컬 Mr.Robot 포트를 Tailscale Serve HTTPS로 공개한 이름을 앱에 등록합니다. Mr.Robot의 파일 전송과 인증은 Tailscale 자체 파일 API가 아니라 동일한 Mr.Robot 프로토콜을 사용하되, PIN과 기기 토큰은 반드시 TLS 안에서 전송됩니다.

## 5. 파일과 작업 동기화

`파일` 화면은 AI 모델을 호출하지 않으므로 **AI 토큰 0**입니다.

- 공유함 또는 등록 작업 폴더에 드래그 앤 드롭 업로드
- PC에서 디스크로 직접 스트리밍 다운로드와 중지
- 모바일에서 업로드·다운로드·취소, 백그라운드 전환 시 부분 파일 자동 정리
- PC 1 → PC 2 직접 전송
- 대화와 사용자 프리셋의 양방향 동기화

PC 간 전송 때 소스 PC의 장기 인증 토큰을 대상 PC에 보내지 않습니다. 소스 PC가 파일 하나 또는 동기화 한 번에만 쓸 수 있는 90초짜리 1회성 전송권을 발급하고, 사용 즉시 폐기합니다. 평문 연결은 실제 loopback/Tailscale 경로로 검증하며, 사용자 도메인의 고정 HTTPS Tunnel은 DNS의 모든 응답이 공인 주소인지 확인한 뒤 한 주소에 고정하고 원래 도메인의 TLS 인증서를 검증합니다. 작업 동기화는 기기별 `작업 동기화` 권한을 별도로 확인하며, 양쪽에서 같은 대화를 수정했다면 한쪽을 덮지 않고 `동기화 충돌 복사본`으로 보존합니다.

설정이나 대화 저장 중 PC가 꺼져 JSON이 손상되어도 원본 바이트를 `.corrupt-...` 파일로 격리하고 마지막 정상 백업에서 복구합니다. 특정 공급자의 DPAPI 키만 읽지 못할 때도 다른 공급자와 설정을 초기화하지 않으며, 해당 키만 다시 연결하도록 표시합니다.

## 6. 개인 근무 캘린더

PC의 `일정` 화면은 일반 일정과 별도로 개인 근무표를 실제 월간 달력으로 표시합니다. 관리자 PC에서 매크로 없는 `.xlsx` 파일, 대상 연도, 행 식별값과 선택적 그룹 식별값을 지정해 가져옵니다.

- 가져오기는 Excel 파일을 OS의 **읽기 전용 모드**로 한 번만 엽니다. 셀·수식·서식·파일 수정 시각을 저장하거나 원본/SharePoint 문서를 덮어쓰는 코드는 없습니다.
- Microsoft 로그인이 필요한 내부 문서는 사용자가 로그인된 환경에서 `.xlsx`로 받아 선택합니다. Mr.Robot은 Microsoft 자격 증명을 수집하거나 SharePoint 원본을 수정하지 않습니다.
- 대상 행에서 파생한 날짜·근무 상태·근무지 이름만 Windows DPAPI(CurrentUser)로 암호화해 `~/.mr-robot/private/work-calendar/state.bin`에 저장합니다. 원본 통합 문서, 행 식별값과 그룹 식별값은 보관하지 않습니다.
- `.xlsx`, `.xls`, `.csv`, 인증서·개인키 확장자는 저장소 기본 `.gitignore`에서 차단됩니다. 실제 이름·주소·내부 URL·NAVER 인증값을 소스나 문서 예시에 넣지 마세요.
- 토·일요일과 대한민국 공휴일은 서울 날짜 기준으로 휴무 처리됩니다. 수동 수정은 특정 날짜의 근무·재택·휴무를 우선 적용하고, 수동 값을 지우면 Excel/공휴일 값으로 돌아갑니다.
- 모바일에는 원본 파일이 전송되지 않습니다. PC의 `연결 기기`에서 해당 기기에 **개인 근무 캘린더** 권한을 별도로 허용해야 조회할 수 있으며, 읽기 전용 기기는 수정할 수 없습니다.

집 주소와 근무지 주소를 저장한 뒤 NAVER Maps Client ID/Secret과 주소 전송 동의를 PC에서 설정하면 당일 자동차 거리·예상 시간을 한 번 조회할 수 있습니다. 주소는 동의한 조회 때만 NAVER Maps API로 전송하고, 내부 근무지 이름은 고정된 일반 이름으로 바꿉니다. 좌표·거리·시간 응답은 저장하거나 캐시하지 않습니다. NAVER의 공식 REST API가 자동차 길찾기만 제공하므로 지하철·버스와 도보는 NAVER 지도 경로 화면을 엽니다. Windows에 지도 앱 URL 처리기가 없으면 엄격히 검증한 `map.naver.com` 길찾기 화면으로 전환하며, 자동차 거리 API가 비활성화되어도 지도 경로 버튼은 계속 사용할 수 있습니다. 인증값과 집/근무지 주소는 위 DPAPI 암호문에만 저장되고 모바일로 인증값을 반환하지 않습니다. PC의 **인증정보 삭제** 버튼으로 Client ID/Secret과 전송 동의를 지울 수 있으며, 암호화 복구본도 삭제 후 최신 상태로 함께 교체됩니다. 기기 권한이나 인증 연결이 끊기면 모바일의 근무표·주소·경로 결과와 편집값은 즉시 지워집니다.

2026년 공휴일은 [한국천문연구원 월력요항](https://www.kasi.re.kr/kor/publication/post/newsMaterial/32031)과 2026년 개정 [관공서의 공휴일에 관한 규정](https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900012119)을 반영합니다. 이후 연도는 서울 시간대의 현행 기본 규칙으로 계산하므로 정부의 임시공휴일·선거일 발표가 있으면 앱 업데이트가 필요할 수 있습니다.

## 7. 권한

- **읽기 전용**: 파일과 상태 조회만 허용
- **변경 전 확인**: 실행·변경 전에 현재 대화에서 승인
- **작업 폴더 허용**: 선택한 작업 폴더 내부에서 자동 실행
- **전체 허용**: 기기별 상한과 전역 상한 안에서 PC 작업 허용

대화 권한은 전역 정책과 연결 기기 권한보다 높아질 수 없습니다. 제공자 키, 플러그인 설치, 의존성 설치, 기기 승격, 네트워크 공개 같은 제어판 작업은 PC 관리자 연결에서만 가능합니다. 모바일·브라우저 연결에서는 상태는 볼 수 있지만 관리자 버튼은 비활성화되고 이유가 표시됩니다.

## 8. CTF와 Docker

CTF 프리셋은 사용자가 지정한 작업 폴더만 샌드박스에 연결합니다. Docker 실행은 CPU·메모리·프로세스·시간 상한을 가지며, 취소·시간 초과·앱 종료 시 프로세스와 컨테이너를 함께 정리합니다. 호스트의 다른 경로, symlink, junction을 통해 작업 폴더 밖으로 나갈 수 없습니다.

CTF는 본인이 소유하거나 명시적으로 허가받은 문제·워게임 환경에서만 사용하세요. 일반 로컬 작업은 Docker 플러그인을 끄고 단일 Codex/Claude 에이전트로 실행할 수 있습니다.

## 9. 보안 도구 플러그인과 독립 포털

플러그인 화면의 `모의해킹` 카테고리에는 Resource Archiver, SSL/TLS Inspector, WebCrypto Runtime Observer가 있습니다. 각 카드의 `작업 화면`에서 대상 소유·허가 확인과 실행별 승인을 거쳐 사용하세요. 모두 Mr.Robot의 독립 구현이며 Save All Resources 확장 프로그램이나 공식 `sslscan`의 소스·실행 파일을 포함하지 않습니다.

독립 포털에서 Resource Archiver의 사전 점검은 네트워크 요청 0회이고, ZIP 보관은 동시 요청 1개·재시도 0회·물리 GET 최대 20회·전체 30초로 제한됩니다. SSL/TLS Inspector의 `quick`은 프로토콜 핸드셰이크 4회만 수행하고, `standard`는 여기에 대표 암호군 최대 12회만 추가하므로 TLS 연결은 총 최대 16회입니다.

Runtime Observer는 다음 세 흐름을 지원합니다.

1. 최대 256 KiB의 관련 JavaScript를 붙여넣어 네트워크 요청 없이 WebCrypto/TextEncoder 후보를 찾습니다. 붙여넣은 코드는 실행하거나 저장하지 않습니다.
2. 소스가 없으면 `crypto.subtle.encrypt` 입력과 `crypto.subtle.decrypt` 완료 결과를 기본 후보로 안내합니다.
3. 정확한 허용목록의 HTTPS 443 URL을 별도 임시 Chrome/Edge 프로필에서 기본 10초·20요청으로 관찰합니다. 기존 브라우저 로그인이나 쿠키는 사용하지 않습니다.

관찰 기본값은 메타데이터 전용입니다. 평문 최대 128바이트 미리보기는 별도 확인 후 새 세션에서만 켤 수 있고 디스크나 브라우저 저장소에 남기지 않습니다. 포털의 변경 기능은 네이티브 설정에서 따로 켜야 합니다. 그 뒤에도 평문 미리보기를 켠 같은 세션에서 실제 관찰된 **잘리지 않은 동일 단계의 평문**과 정확히 일치하는 UTF-8 literal(1~64바이트)만 실행별 승인 후 등록할 수 있고, 다음 바이트 일치 한 번에 적용되면 즉시 폐기됩니다. 치환값도 1~64바이트이며 정규식이나 코드는 받을 수 없습니다. POST/PUT/PATCH를 쓰는 세션은 상태 변경을 따로 확인해야 하며 DELETE는 항상 막힙니다.

도메인에서 도구를 따로 열려면 Windows 네이티브 앱에서 `설정 → 도구 포털`을 엽니다. 포털 전용 비밀번호(UTF-8 12바이트 이상)를 처음 저장하면 포털이 활성화됩니다. 능동 접속을 실행하려면 와일드카드·접미사 매칭·포트·경로 없이 정확한 대상 DNS 이름을 허용목록에 등록해야 합니다. Resource Archiver로 ZIP을 만들 때만 등록 작업 폴더가 필요하고, POST/PUT/PATCH와 literal 변경은 필요할 때만 포털 변경 기능을 켭니다. 그러면 아래 주소를 개별로 사용할 수 있습니다.

- `/tools/resource-archiver`
- `/tools/sslscan`
- `/tools/runtime-hook`

포털은 설정 전에는 꺼져 있고 비밀번호 원문을 저장하지 않습니다. 로컬 PC에서는 loopback으로 열 수 있습니다. 외부 도메인은 실행·검증된 Cloudflare Named Tunnel과 호스트 전체 Access 보호가 모두 있어야 하며 포털 비밀번호는 추가로 요구됩니다. Quick Tunnel이나 일반 LAN HTTP에는 포털을 공개하지 않습니다. 설정 변경·비활성화·로그아웃은 활성 포털 세션과 관찰 작업, 아직 쓰지 않은 ZIP 다운로드 권한을 폐기합니다.

Resource Archiver 포털의 ZIP 링크는 같은 로그인에서만 쓸 수 있고 2분 뒤 만료되며 한 번 다운로드하면 폐기됩니다. 브라우저가 출력 경로나 작업 폴더를 지정할 수 없으므로, 파일은 네이티브 앱에서 선택한 작업 폴더의 `resource-archives` 아래에 남습니다.

## 10. 설치 파일

- Windows x64: `release/Mr.Robot-Setup-0.4.4-x64.exe`
- Android: 기존 릴리스 키로 검증된 `release/mobile/Mr.Robot-Mobile-0.4.1.apk` 유지

0.2.1 이하 모바일 시험판은 Android 디버그 인증서로 서명됐고, 0.3.0부터는 Mr.Robot 전용 릴리스 인증서를 사용합니다. Android 보안 정책상 기존 시험판 위에 바로 덮어쓸 수 없으므로, 필요한 대화·프리셋을 먼저 PC와 동기화한 뒤 기존 앱을 한 번 제거하고 0.4.1을 설치해 다시 페어링하세요. 0.3.0 이후 사용자는 같은 릴리스 키와 더 높은 versionCode 16을 사용하는 0.4.1로 바로 업데이트할 수 있습니다.

현재 Windows 설치본은 상용 Authenticode 인증서가 없어 Windows SmartScreen 확인이 나올 수 있습니다. GitHub 공개 릴리스의 SHA-256과 내려받은 파일의 해시를 대조하세요. Android APK는 릴리스 키로 서명되며, 개발자는 `C:\Users\<사용자>\.mr-robot\signing`의 keystore와 DPAPI 보호 암호를 안전하게 백업해야 이후 업데이트를 같은 서명으로 배포할 수 있습니다. DPAPI 파일만 다른 PC로 복사해서는 복호화할 수 없습니다.

개발 환경에서는 저장소 루트에서 다음을 실행합니다.

```powershell
npm install
npm run build
npm test
npm run test:leak
```

Android 릴리스는 Windows React Native/NDK 제약 때문에 `C:\MrRobot`처럼 ASCII 문자만 포함한 체크아웃에서 `scripts/build-mobile-release.ps1`을 실행해 만듭니다. 스크립트는 기존 공식 서명키와 인증서 지문을 검증하며, 키가 없을 때는 자동으로 새 ID를 만들지 않습니다. Windows 설치본은 `npm run build:installer`로 만듭니다.
두 패키지에는 `THIRD_PARTY_NOTICES.txt`가 포함되며, `npm run notices`로 프로덕션 의존성 고지를 다시 생성할 수 있습니다.
