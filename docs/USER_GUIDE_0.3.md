# Mr.Robot 0.3 빠른 사용 가이드

## 1. PC에서 바로 시작

Windows 설치 파일을 실행한 뒤 Mr.Robot을 켜면 PC 앱은 다른 기기를 연결하지 않아도 단독으로 동작합니다. 처음 한 번만 외부 도구 검사가 열리며, 설치된 항목은 건드리지 않고 누락된 선택 항목만 설치할 수 있습니다. Codex CLI와 Claude Code의 로그인은 각 공식 로그인 화면에서 직접 진행합니다.

대화 상단에서 다음 항목을 대화마다 따로 저장할 수 있습니다.

- **시나리오**: `단일 모델` 또는 저장된 복합 트리
- **모델**: 시나리오 자동 배정 또는 특정 제공자·모델
- **컨텍스트**: 추론 강도, 작업 폴더, 액세스 권한
- **대화 관리**: 고정, 이름 변경, 보관, 복원, 삭제

작업 폴더가 필요하면 컨텍스트 패널의 `폴더 추가`를 누릅니다. 데스크톱 앱에서는 Windows 폴더 선택기가 열리고, 원격으로 연결한 기기에서는 PC 관리자가 미리 등록한 폴더만 선택할 수 있습니다.

## 2. 단일 모델과 복합 시나리오

`단일 모델`은 선택한 Codex·Claude·API 모델을 한 개의 네이티브 에이전트 실행 경로로 사용합니다. 대화 기록, 작업 폴더, 권한, 도구 승인, 취소·끼워넣기, 파일 첨부는 Mr.Robot이 공통으로 관리합니다.

복합 시나리오는 필요한 경우에만 여러 모델 호출을 사용합니다. 기본 제공 프리셋은 삭제하거나 덮어쓸 수 없으며, 복사해 만든 사용자 프리셋은 자유롭게 수정할 수 있습니다.

- **Mr.Robot 스마트 캐스케이드**: 저비용 모델부터 시작하고 검증이 부족할 때만 상위 모델 사용
- **저비용·고효율 투표**: 여러 후보가 짧게 독립 검토한 뒤 결과를 투표·검증
- **순차 실행·검증**: 실행자 결과를 별도 검증 노드가 확인하고 필요할 때만 재작업
- **분류·회의·검증 혼합**: 요청 분류, 그룹 토론, 그룹 간 의견 교환, 최종 검증 조합
- **CTF 경쟁 스웜**: 격리된 Docker 작업공간에서 여러 해결자가 정보를 공유하며 제한 횟수 안에서 경쟁

동일 파일과 긴 문서는 컨텍스트 브로커가 한 번 읽어 정규화한 뒤 해시 기반 캐시로 재사용합니다. OpenAI·Anthropic의 공급자 캐시 사용량도 수집하며, 설정의 사용량 화면에서 입력·출력·추론·캐시 재사용 토큰을 확인할 수 있습니다.

## 3. 모바일 연결

모바일 APK를 설치하고 PC 앱의 `설정 → 모바일·기기 연결`에서 PIN 또는 QR을 사용합니다. PIN은 관리자 비밀키가 아니라 폐기 가능한 기기별 토큰을 발급합니다. 새 연결은 기본적으로 `변경 전 확인` 이하 권한이며, 더 높은 권한은 PC 앱에서 해당 기기를 직접 승격해야 합니다.

일반 Wi-Fi/LAN의 평문 HTTP 주소는 인증정보 노출을 막기 위해 사용할 수 없습니다. 휴대폰 VPN 없이 쓰려면 PC 플러그인에서 Quick Link를 시작하고 표시된 HTTPS 주소/QR을 등록하세요. Tailscale을 이미 쓰는 경우에는 PC의 사설 Mesh 수신을 켠 뒤 `100.64.0.0/10` 주소를 사용할 수 있습니다.

모바일 채팅 입력창은 키보드가 올라오면 함께 이동하고, 키보드가 열린 동안 하단 탭을 숨겨 입력 영역을 확보합니다. 다른 대화를 보고 있어도 실행 중인 대화별 상태가 분리되며, 실행 중지와 추가 지시가 원래 작업에만 전달됩니다.

## 4. VPN 없이 외부에서 연결

Tailscale은 선택 플러그인입니다. 금융 앱 때문에 휴대폰 VPN을 계속 켜기 불편하면 다음 흐름을 사용합니다.

1. PC 앱의 `플러그인 → 원격 연결`에서 **Cloudflare Quick Link**를 선택합니다.
2. 처음 한 번만 `cloudflared 설치`를 누르고, 이후 `Quick Link 시작`을 누릅니다.
3. 표시된 임시 HTTPS 주소 또는 QR을 모바일에 등록합니다. PIN은 5분 동안 한 번만 쓸 수 있고 성공 즉시 새 PIN으로 바뀝니다.
4. 사용을 마치면 `중지`를 누릅니다. PC 앱을 종료해도 링크와 전송은 정리됩니다.

Quick Link는 휴대폰에 VPN을 설치하지 않고 HTTPS/WSS로 연결합니다. 임시 주소는 다시 시작할 때 바뀔 수 있으며, 상시 고정 주소가 필요한 경우에는 Cloudflare named tunnel 또는 별도 Google/Firebase relay 인프라가 필요합니다. 자격증명과 서버 인프라가 없는 공개 빌드에서는 안전하지 않은 공용 relay를 자동으로 만들지 않습니다.

Tailscale을 선호하면 플러그인에서 켠 뒤 PC·모바일을 같은 계정에 연결하면 됩니다. Mr.Robot의 파일 전송과 인증은 Tailscale 자체 파일 API가 아니라 동일한 Mr.Robot 프로토콜을 사용합니다.

## 5. 파일과 작업 동기화

`파일` 화면은 AI 모델을 호출하지 않으므로 **AI 토큰 0**입니다.

- 공유함 또는 등록 작업 폴더에 드래그 앤 드롭 업로드
- PC에서 디스크로 직접 스트리밍 다운로드와 중지
- 모바일에서 업로드·다운로드·취소, 백그라운드 전환 시 부분 파일 자동 정리
- PC 1 → PC 2 직접 전송
- 대화와 사용자 프리셋의 양방향 동기화

PC 간 전송 때 소스 PC의 장기 인증 토큰을 대상 PC에 보내지 않습니다. 소스 PC가 파일 하나 또는 동기화 한 번에만 쓸 수 있는 90초짜리 1회성 전송권을 발급하고, 사용 즉시 폐기합니다. 작업 동기화는 기기별 `작업 동기화` 권한을 별도로 확인하며, 양쪽에서 같은 대화를 수정했다면 한쪽을 덮지 않고 `동기화 충돌 복사본`으로 보존합니다.

설정이나 대화 저장 중 PC가 꺼져 JSON이 손상되어도 원본 바이트를 `.corrupt-...` 파일로 격리하고 마지막 정상 백업에서 복구합니다. 특정 공급자의 DPAPI 키만 읽지 못할 때도 다른 공급자와 설정을 초기화하지 않으며, 해당 키만 다시 연결하도록 표시합니다.

## 6. 권한

- **읽기 전용**: 파일과 상태 조회만 허용
- **변경 전 확인**: 실행·변경 전에 현재 대화에서 승인
- **작업 폴더 허용**: 선택한 작업 폴더 내부에서 자동 실행
- **전체 허용**: 기기별 상한과 전역 상한 안에서 PC 작업 허용

대화 권한은 전역 정책과 연결 기기 권한보다 높아질 수 없습니다. 제공자 키, 플러그인 설치, 의존성 설치, 기기 승격, 네트워크 공개 같은 제어판 작업은 PC 관리자 연결에서만 가능합니다. 모바일·브라우저 연결에서는 상태는 볼 수 있지만 관리자 버튼은 비활성화되고 이유가 표시됩니다.

## 7. CTF와 Docker

CTF 프리셋은 사용자가 지정한 작업 폴더만 샌드박스에 연결합니다. Docker 실행은 CPU·메모리·프로세스·시간 상한을 가지며, 취소·시간 초과·앱 종료 시 프로세스와 컨테이너를 함께 정리합니다. 호스트의 다른 경로, symlink, junction을 통해 작업 폴더 밖으로 나갈 수 없습니다.

CTF는 본인이 소유하거나 명시적으로 허가받은 문제·워게임 환경에서만 사용하세요. 일반 로컬 작업은 Docker 플러그인을 끄고 단일 Codex/Claude 에이전트로 실행할 수 있습니다.

## 8. 설치 파일

- Windows x64: `release/Mr.Robot-Setup-0.3.0-x64.exe`
- Android: `release/mobile/Mr.Robot-Mobile-0.3.0.apk`

0.2.1 이하 모바일 시험판은 Android 디버그 인증서로 서명됐고, 0.3.0부터는 Mr.Robot 전용 릴리스 인증서를 사용합니다. Android 보안 정책상 기존 시험판 위에 바로 덮어쓸 수 없으므로, 필요한 대화·프리셋을 먼저 PC와 동기화한 뒤 기존 앱을 한 번 제거하고 0.3.0을 설치해 다시 페어링하세요. 이후 0.3.x 릴리스는 같은 키를 유지하므로 정상 업데이트할 수 있습니다.

현재 Windows 설치본은 상용 Authenticode 인증서가 없어 Windows SmartScreen 확인이 나올 수 있습니다. GitHub 공개 릴리스의 SHA-256과 내려받은 파일의 해시를 대조하세요. Android APK는 릴리스 키로 서명되며, 개발자는 `C:\Users\<사용자>\.mr-robot\signing`의 keystore와 DPAPI 보호 암호를 안전하게 백업해야 이후 업데이트를 같은 서명으로 배포할 수 있습니다. DPAPI 파일만 다른 PC로 복사해서는 복호화할 수 없습니다.

개발 환경에서는 저장소 루트에서 다음을 실행합니다.

```powershell
npm install
npm run build
npm test
npm run test:leak
```

Android 릴리스는 `scripts/build-mobile-release.ps1`, Windows 설치본은 `npm run build:installer`로 만듭니다.
두 패키지에는 `THIRD_PARTY_NOTICES.txt`가 포함되며, `npm run notices`로 프로덕션 의존성 고지를 다시 생성할 수 있습니다.
