# V.E.R.A 0.7.2

## Discord 사용자별 GPT-6 모델 허용

- 서버 관리자는 `/robot model-limit user:@사용자 ceiling:sol`로 GPT-6 Sol과 하위 등급을, `ceiling:astra`로 Astra와 Sol을 포함한 하위 등급을 허용할 수 있습니다. 일반 사용자는 `/robot model` 또는 티켓의 **모델 선택**에서 현재 계정과 정책에 모두 허용된 모델을 선택합니다.
- 기존 등급표에 없던 정확한 `gpt-6-sol` ID를 Sol 등급에 추가했습니다. 이는 제품의 관리용 등급이며 벤치마크 순위가 아닙니다.
- 일반 사용자의 기본 정책은 기존 모델 이용을 유지하면서 GPT-6 계열에는 관리자 허가를 요구합니다. 기존 명시적 `sol`·`astra` 정책은 유지됩니다. 관리자 자신의 기본 정책은 전체 모델이며 명시적 제한을 설정하면 그 제한이 적용됩니다.
- `default`는 개별 허가를 회수하고, `unlimited`는 모든 공급자의 모델을 명시적으로 허용합니다. 이전 버전은 `unlimited`를 저장하지 않았으므로 해당 의도를 복원할 수 없습니다. 그런 사용자는 GPT-6 사용 허가를 다시 설정해야 합니다.
- 모델 정책은 서버·사용자별로 보존되며 같은 서버의 모든 티켓에 적용됩니다. 실행 중인 대상 사용자의 정책 변경은 먼저 중지를 요구합니다. PC 접근 권한, `allow_ai` 역할과 티켓 소유권은 별도이며 모델 허용이 PC 전체 접근을 부여하지 않습니다.
- 모델 선택 메뉴에 **허용 모델 새로고침**을 추가했습니다. 호스트가 반환한 허용 목록에 없는 이전 선택을 다시 끼워 넣지 않습니다. 계정의 모델 목록을 확인하지 못하면 선택·실행을 중단하고 안내합니다.
- 설정 저장, 실행 접수와 실제 모델 호출에서 정책을 검사합니다. 모델 목록을 기다리는 사이 권한이 회수되는 경우도 다시 검사하며 다른 모델로 임의 대체하지 않습니다. 공급자의 계정 권한·구독 약관·한도는 이 기능과 별개입니다.

## 검증 및 배포 범위

관리자/일반 사용자, 허가/회수, 서버·사용자 격리, 오래된 선택 메뉴, 직접 입력과 모델 호출 직전 검사에 대한 회귀 테스트를 포함합니다. 공개 테스트는 가짜 Discord 이벤트와 로컬 호스트를 사용하며 실제 Discord 사용자의 권한을 임의 변경하지 않습니다.

관리형 샌드박스는 실제 Docker 엔진과 기존 로컬 이미지가 있을 때만 실행하는 선택적 검사를 제공합니다. 엔진 부재로 건너뛴 결과를 컨테이너 성공으로 계산하지 않습니다. Docker 설치·초기화·이미지 다운로드를 플러그인이 자동 수행하지 않습니다.

이번 검증에서는 로컬 Docker Linux 엔진과 공식 Python 이미지를 명시적으로 준비한 뒤 실제 플러그인 통합검사를 통과했습니다. UID·capabilities·seccomp, 읽기 전용 루트, tmpfs·cgroup 제한, 외부 네트워크 차단, 범위별 분리·재사용, 시간 초과·출력 초과·취소·독립 watchdog과 테스트 소유 컨테이너 정리를 확인했습니다. 이는 해당 로컬 환경의 기능검사이며 모든 호스트에서의 격리 보장이나 AI 정확도 벤치마크가 아닙니다.

기존 설치 ID·프로필·페어링·MIT와 제3자 고지를 유지합니다. Windows 설치 파일은 코드 서명 인증서 없이 빌드되며 Android APK는 기존 공식 키로 서명합니다. 이번 모바일 배포는 APK 업로드이며 사용자 기기에 자동 설치하지 않습니다.
