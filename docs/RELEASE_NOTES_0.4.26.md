# v0.4.26 — Discord 첨부 다운로드 오판 수정

## 확인한 원인과 수정

- Discord 첨부 메타데이터의 크기와 실제 CDN 응답 크기가 다르면 정상 파일도 다운로드 실패로 처리하던 오류를 수정했습니다. 실제 장애가 난 이미지에서 CDN은 HTTP 200과 완전한 PNG를 반환했지만 메타데이터에는 다른 크기·형식이 기록되어 있었습니다.
- 메타데이터의 크기를 파일 무결성 검사로 사용하지 않습니다. 실제 수신 바이트로 SHA-256, 암호화 보관 메타데이터와 요청별 용량을 계산합니다. 더 큰 표현과 더 작은 표현 모두 지원합니다.
- 실제 수신 용량 제한은 파일당 25MiB, 한 요청 합계 50MiB로 유지하며, 각 파일을 받을 때 남은 실제 용량을 적용합니다. Discord 첨부 호스트·채널·파일 ID 검증, 공개 IP 검증과 DNS 고정, 리디렉션 금지, 티켓별 AES-GCM 암호화 및 접근 격리를 유지합니다.

## 실패 복구와 진단

- 일시적인 DNS·네트워크·응답 본문 오류 및 재시도 가능한 HTTP 오류에는 짧은 대기 후 다운로드만 최대 3회 시도합니다. 파일 하나의 다운로드·재시도 전체는 최대 60초이며 사용자가 중지하면 즉시 취소합니다. AI 질문을 다시 실행하지 않습니다.
- HTTP 접근 거부/만료·삭제, DNS, 연결, 시간 초과, 실제 용량 초과, 저장소 공간·권한·암호화 키 실패를 구분한 안내를 제공합니다. 403/404/410과 정책 차단은 반복하지 않습니다. 서명 URL, 토큰, 로컬 경로, 원시 오류는 Discord 메시지나 첨부 실패 로그에 포함하지 않습니다.
- 암호화 키 저장 실패 시 메모리에만 남은 임시 키를 다음 저장에 재사용하지 않도록 수정했습니다. 기존 키나 첨부를 초기화하지 않습니다.

## 검증과 적용 범위

- 장애가 난 실제 첨부를 수정된 수신 경로로 다시 내려받아, 별도 임시 저장소에서 Windows DPAPI와 AES-GCM 저장 및 새 저장소 인스턴스의 재열기를 확인했습니다. 검증용 임시 사본은 제거했으며 사용자의 기존 보관함과 대화는 변경하지 않았습니다. AI 추론을 실행하거나 Discord에 테스트 메시지를 게시하지 않았습니다.
- 크기 차이, 실제 용량 한도, 재시도 상한, 중지, 전체 시간 제한, 원인별 오류, 암호화 키 실패 후 복구에 대한 회귀 테스트 17개를 추가했습니다.
- Discord 권한·세션·격리·첨부 선택·보관 테스트, 리소스 다운로드 보안 테스트 및 에이전트 타입 검사를 수행합니다.
- 실행 PC의 에이전트 수정입니다. 모바일 코드는 변경하지 않았고 기존 APK를 계속 사용할 수 있습니다. 이미 실패한 메시지를 자동으로 재실행하지는 않으므로 업데이트 후 해당 첨부를 다시 보내 주세요.
- 이번 수정은 만료된 Discord 링크를 영구 링크로 만들거나 자동 갱신하는 기능이 아닙니다. 403/404/410이 실제로 발생한 경우 원본 재첨부가 필요할 수 있습니다.

PC 설치 마법사(EXE), 공개 소스 ZIP 및 SHA-256 체크섬을 제공합니다. 개인 첨부, 봇 연결정보, 서명 URL과 키는 배포에 포함하지 않습니다.
