# Mr.Robot 0.6.13 적응형 협업과 문맥 효율 개선

고정된 계획·풀이·검토 호출을 모든 요청에 실행하는 대신, 최종 모델이 먼저 작업하고 필요한 보조 조사만 요청하는 선택형 실행 방식을 추가했습니다. 기존 단일·순차·회의 설정과 사용자 기본값은 자동으로 바꾸지 않습니다. 이 구조 변경 자체가 정확도 향상을 입증하는 것은 아닙니다.

## 사용 방법

설정의 시나리오 실행 방식에서 **적응형 협업**을 선택하거나, 프리셋에서 **적응형 협업 · 필요할 때만 보조**를 선택합니다. 마지막 노드가 실행과 최종 검증을 담당하며 앞 노드는 읽기 전용 보조 모델입니다. 특정 모델을 쓰려면 해당 노드의 공급자와 모델을 지정하세요. 보조 모델을 생략한 호출은 주 모델을 사용합니다.

네이티브 Codex의 보조 실행은 기존과 동일하게 감사 전용 토큰 정책과 연결된 대화 세션이 필요합니다. 유한 토큰 예산을 보조 모델에 중복 대여하지 않습니다. 조건을 충족하지 못하면 보조 도구를 제공하지 않으며 권한이나 예산을 자동 확대하지 않습니다. 격리된 Discord 일반 사용자에게 PC 읽기 권한을 추가하지 않습니다. Claude를 포함한 다른 네이티브 공급자의 보조 실행 지원을 새로 추가한 버전은 아닙니다.

## 변경 사항

- 최종 모델은 문제를 먼저 해결하고, 독립 조사나 구체적인 미해결 쟁점이 있을 때만 등록된 보조 모델에 요청합니다. 없는 모델 이름을 임의로 입력하거나 더 싼 모델로 몰래 대체하지 않습니다.
- 보조 작업에는 최대 두 개의 동시 실행, 작업별 문맥 분리, 읽기 전용 도구, 기존 취소와 사용량 계측이 적용됩니다. 주 모델만 파일 변경과 최종 실행을 담당합니다.
- 순차 단계에 원래 질문을 두 번 넣던 중복을 제거했습니다. 원래 질문과 근거의 앞부분을 꼬리 자르기로 잃지 않도록 보존하고, 보조 제안만 크기 제한과 중복 제거를 적용합니다.
- 순차 단계가 실패하거나 빈 답변·미처리 도구 요청을 반환하면 뒤의 의존 검토 호출을 생략합니다. 최종 모델에는 누락된 단계가 있음을 알리고 독립 검증을 요구합니다. 사용자 취소나 예산 초과는 복구 명목으로 계속 실행하지 않습니다.
- 회의 구성원들의 제안이 이전 라운드와 모두 정확히 같으면 다음 반복 토론을 생략하되 최종 검증은 유지합니다. 문장이 같다는 이유로 정답이나 합의가 검증됐다고 판단하지 않습니다.
- PC와 모바일에 새 실행 방식의 이름을 표시합니다. 이번 작업에서 APK나 GitHub Release 바이너리를 자동 게시하지 않습니다.

논문 근거와 검증 범위는 [최적화 평가 기록](OBSERVATION_0.6.13_2026-10-03.md)을 참고하세요.

## 검증 결과

전체 회귀 테스트, PC·모바일 타입 검사, 실제 Electron 화면 렌더링·복구 검사를 통과했습니다. 실제 앱에서 공개 ARC-AGI-2 개발 회귀 두 문항을 각 방식으로 한 번씩 풀어 세 방식 모두 2/2 정답이었습니다. 적응형은 순차 대비 합산 시간 61.3%, 보고 토큰 27.5%를 줄였으나, 단일보다 시간 15.0%, 토큰 2.4%가 더 들었습니다. 따라서 일반 정확도 향상이나 단일 실행 대비 우위를 주장하지 않습니다. 측정 범위와 보조 호출 여부는 평가 기록에 공개했습니다.
