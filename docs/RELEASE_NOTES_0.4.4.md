# Mr.Robot 0.4.4

0.4.4는 Windows 앱을 최신 0.4.3 기반으로 통합하고, 대화 입력 UX와 PC 브랜드 표시를 정리한 릴리스입니다.

## 변경 사항

- PC 입력창 옆에 대화별 **액세스 권한**과 **추론 강도** 드롭다운을 배치했습니다.
- 연결 기기의 권한 상한보다 높은 선택은 잠그고, 서버가 더 낮은 권한을 적용하면 실제 적용값을 안내합니다.
- 설정 저장과 명령 전송의 경합을 막고 실패 시 해당 대화와 사이드바를 안전하게 되돌립니다.
- PC 창·작업 표시줄·Alt+Tab·트레이와 앱 내부 브랜드를 모바일 앱의 전체 아이콘으로 통일했습니다.
- 패키징 단계에서 모바일 아이콘을 런타임에 포함해 다시 예전 32px 내장 아이콘으로 돌아가지 않게 했습니다.
- Android 0.4.1 소스의 키보드 겹침 보정, 권한·추론 입력 컨트롤과 인증 권한 상한 보존을 함께 유지합니다.
- 0.4.3의 전체 실행 토큰 예산, 실패한 동일 요청의 안전한 재시도, 보안 도구 포털 기능을 모두 포함합니다.

## 보안

- 실제 실행 권한은 전역 정책, 연결 기기 상한, 대화 선택 중 가장 제한적인 값입니다.
- 원격 연결과 도구 포털은 기본 OFF이며, 공개 릴리스에는 로컬 자격증명·DPAPI/SecureStore 상태·API 키가 포함되지 않습니다.
- Windows 설치본은 Authenticode 미서명입니다. GitHub Release의 SHA-256을 확인하세요.

## 산출물

- Windows x64: `release/Mr.Robot-Setup-0.4.4-x64.exe`
- Android: 검증된 `release/mobile/Mr.Robot-Mobile-0.4.1.apk` 유지
- 정확한 파일 크기와 SHA-256은 최종 빌드 검증 뒤 이 문서에 추가합니다.
