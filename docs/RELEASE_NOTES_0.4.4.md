# Mr.Robot 0.4.4

0.4.4는 단순 요청의 낭비는 줄이되 어려운 작업의 품질을 고정된 15분 누적 토큰 상한으로 끊지 않도록 실행 예산을 다시 설계한 릴리스입니다.

## 대화별 토큰 정책

- 대화 상단의 권한 선택 바로 옆에 토큰 정책 드롭다운을 추가했습니다.
- 기본 `적응형 · 품질 우선`은 단순 64,000, 표준 192,000, 복합 512,000토큰의 호출 기준에서 시작하고 요청 복잡도, 추론 강도, 입력 문맥, 모델 시나리오와 실제 도구 진행에 따라 품질에 필요한 구간만 확장합니다. 한 실행의 절대 상한은 8,000,000토큰입니다.
- 기존의 전역·기기별 15분 누적 토큰 차단은 제거했습니다. 앞선 어려운 작업의 사용량 때문에 다음 정상 작업이 막히지 않습니다.
- 내장 네이티브 앱의 로컬 관리자만 선택할 수 있는 `무제한 · 감사만`은 Mr.Robot의 누적 토큰 예산으로 실행을 중단하지 않고 사용량만 기록합니다. 네이티브 메인 프로세스와 내장 서버 사이의 짧은 1회성 증명까지 확인하며 모델 공급자의 요금, 계정 한도와 요청 제한은 그대로 적용됩니다.
- 감사 전용 설정은 목적지 PC 네이티브 앱의 로컬 전용 권한입니다. 일반 로컬 브라우저, localhost로 위장한 프록시, 연결 기기, 원격·프록시 연결, REST 실행과 다른 기기에서 가져온 동기화 데이터는 항상 적응형으로 실행됩니다.
- 공급자가 보고한 실제 입력·출력·추론·캐시 토큰과 예상 비용은 그대로 표시하고, 예약량과 실패 중 부분 사용량까지 보수적으로 반영한 `감사 토큰`은 별도 지표로 저장합니다.

## 남아 있는 실행 안전장치

- 무제한은 Mr.Robot의 누적 토큰 차단에만 적용됩니다. 공급자 호출 수, 실행 시간, 스트림·전송 크기, 동시 실행, 시작 빈도, 사용자 취소, 최대 도구 단계와 무진전 반복 차단은 계속 동작합니다.
- 복합 시나리오의 병렬 모델 호출은 전역 48개, 로컬 관리자 32개, 연결 기기별 8개 동시 호출 안에서 실행됩니다. 한 분기가 실패하면 형제 호출을 중단하고 `Promise.allSettled` 방식으로 실제 종료까지 기다린 뒤 슬롯을 반환해 실패 경쟁 중 동시 호출 제한을 우회할 수 없게 했습니다.
- 적응형 모드는 단순 단일 호출에서 작게 시작하고 높은 추론 강도·복합 모델 실행·완료된 도구 라운드에만 제한된 추가 구간을 엽니다.
- 공급자가 비정상 토큰 수치를 반환해도 사용량 저장소가 `NaN`, 음수 또는 무한대로 오염되지 않도록 정규화하고 유한 상한에서 포화시킵니다.

## 스트림 및 플러그인 내구성

- OpenAI 호환 및 Anthropic 스트림에 호스트 소유 deadline과 누적 바이트·행·버퍼 상한을 적용해 끝나지 않는 응답이 감사 모드를 악용하지 못하게 했습니다.
- Runtime Observer의 CDP 입력에도 세션 누적 메시지·바이트와 잘못된 binding 호출 예산을 적용했습니다.

## 검증 범위

- Shared/Agent/Web/Mobile 타입 검사
- 적응형 예산, 네이티브 로컬 관리자용 1회성 감사 권한 증명, localhost 재작성 프록시 차단, 원격·연결 기기 강제 적응형, 대화 동기화와 실제/감사 사용량 분리 집중 테스트
- 공급자 무한 스트림 및 Runtime Observer 반복 입력 집중 테스트
- 데스크톱·모바일·반응형 UI 계약 검사와 권한 옆 드롭다운의 한 화면 시각 확인

직전 기능 릴리스의 전체 회귀를 반복하지 않고 이번 변경 경로만 검증했습니다.

## 설치 파일

- Windows x64: `Mr.Robot-Setup-0.4.4-x64.exe`
- 공개 소스: `Mr.Robot-source-0.4.4.zip`
- SHA-256 목록: `SHA256SUMS-0.4.4.txt`
- Android는 검증된 기존 `Mr.Robot-Mobile-0.4.0.apk`(versionCode 15)를 유지합니다.
- Windows 설치 파일은 아직 Authenticode 서명이 없으므로 Release의 SHA-256 목록으로 무결성을 확인해야 합니다.
