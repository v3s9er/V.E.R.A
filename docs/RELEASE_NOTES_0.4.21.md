# 0.4.21 — 공급자 모델 목록 동기화

- Codex 구독 모델을 고정 목록/도움말 대신 로그인한 CLI의 `model/list`에서 조회합니다. 숨김 모델은 제외하고 페이지를 이어 받아 새 모델을 발견합니다. 별도의 AI 추론 요청이나 API 키 과금 전환은 하지 않습니다.
- 모델 선택창을 열 때 목록을 확인합니다. Codex/Claude CLI 목록의 성공 캐시는 5분 뒤 다음 조회 시 갱신하며, PC·웹·모바일에 수동 새로고침을 제공합니다. 실패하면 마지막 성공 목록 또는 기존 기본 목록을 유지합니다. 수동 갱신 실패는 안내하고 연속 클릭·동시 요청은 합쳐 처리합니다.
- 현재 대화의 선택 모델·공급자·권한은 자동 변경하지 않습니다. 모델 출시 여부와 각 계정/CLI에서의 사용 가능 여부는 별개입니다. CLI 자체를 자동 설치하거나 업데이트하지 않습니다.
- OpenAI 호환 API·Anthropic API·Ollama는 기존 공급자 모델 조회를 이용합니다. Claude CLI는 도움말 탐색/기본 별칭을 재조회하는 제한된 방식이며 Codex와 같은 계정별 실시간 카탈로그라고 표시하지 않습니다.
- Discord도 같은 호스트 모델 조회를 이용합니다. 기존 사용자별 모델 상한은 유지하며 새 미분류 모델을 임의로 하위 등급에 배정하지 않습니다.
- 이전 공개 릴리스 0.4.14 이후 누락된 권한 분리·첨부파일·재연결·격리 작업·원본 보관·MIT·배포 감사 내용을 0.4.20 릴리스 설명에 보완했습니다.

검증: 공유/에이전트/웹/모바일 TypeScript, 모델 카탈로그 프로토콜·페이지 처리·숨김 항목·오류·시간 초과·캐시 만료·강제 갱신·권한 상한 테스트 및 PC/모바일 UI 계약 테스트를 통과했습니다. 원격 파일 암호화·권한 경계 회귀 테스트도 통과했습니다. 설치된 PC 앱을 0.4.21로 업데이트한 뒤 실제 RPC 경로에서 Codex 모델 7개(gpt-6-astra 포함)를 확인했습니다. EXE/APK의 알려진 민감정보 형식·경로 검사도 통과했습니다. APK는 versionCode 26이며 기존 Android 서명 인증서를 유지합니다. 모바일 실기기 화면 조작은 이번 검증에 포함하지 않았습니다.
