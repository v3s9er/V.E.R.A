# v0.4.27 — 로컬 네이티브 실행·응답성 및 프로젝트 작업 공간

## 로컬 네이티브 실행

- Codex app-server의 실행 중 추가 지시를 `turn/steer`로 전달합니다. 활성 실행 ID와 수신 확인을 검증하고, 확인된 지시만 대기열에서 제거합니다. 현재 작업을 중단하거나 새 AI 조정 호출을 추가하지 않습니다.
- 추가 지시와 후속 실행의 실제 대화 기록을 저장하여 다음 질문의 세션 재사용이 깨지던 문제를 수정했습니다. 기존 계정, 모델, 추론 수준, 권한 및 예산 정책은 유지합니다.
- `phase` 정보가 없는 공개 응답도 완료 이벤트를 기다리지 않고 스트리밍합니다. 모델의 비공개 추론 내용은 전달하지 않습니다.
- 승인된 네이티브 작업은 최대 4개 실행 슬롯과 최대 32개 FIFO 대기열을 사용합니다. 대기 중 취소와 종료 경합을 처리하고, 오래 사용하지 않은 유휴 워커부터 정리합니다. 상위 계정 한도와 프로젝트 쓰기 충돌 검사는 우회하지 않습니다.
- 중지는 CLI에 먼저 요청하고, 완료 확인이 1.5초 안에 오지 않으면 프로세스 트리를 종료합니다. 취소·불확실한 작업을 자동으로 재실행하지 않습니다.
- 유휴 워커가 첫 요청의 대화 기록·콜백을 계속 참조하던 부분을 제거했습니다. 입력 대기열이 가득 차면 이전 지시를 조용히 버리지 않고 안내합니다.

## 프로젝트·실행 상태·UI

- 프로젝트 생성, 기존 폴더 연결, 이름·지침 수정, 프로젝트별 대화 목록을 추가했습니다. 프로젝트 연결을 해제해도 폴더나 대화는 삭제하지 않습니다.
- 삭제된 프로젝트의 대화가 다른 폴더를 자동으로 사용하지 않도록 했습니다. 같은 프로젝트의 쓰기 작업은 겹치지 않고, 서로 다른 프로젝트와 읽기 작업은 기존 실행 한도 안에서 병행합니다.
- 실행 ID, 진행 단계, 제한된 작업 이력과 부분 응답을 보관하여 연결 복구 시 표시합니다. 호스트 재시작 후 임의의 PC 작업을 재생하는 기능은 아닙니다.
- PC의 프로젝트 사이드바와 좁은 창의 서랍형 탐색, 간소화된 입력창 및 실행 상태 표시를 추가했습니다. 낮은 창 높이에서도 보내기·중지 버튼이 내부 스크롤에 숨지 않도록 수정했습니다.
- 모바일 프로젝트 선택과 간소화된 진행 상태 UI의 소스도 포함합니다. 이번 배포의 설치 파일은 PC용이며 Android 키보드 동작의 실기기 검증 및 새 APK는 포함하지 않습니다.
- 독립적인 읽기 도구만 최대 3개 병렬 실행하고 변경·컴퓨터 조작은 순서를 유지합니다. 오류·취소·실패한 실행을 성공으로 집계하지 않습니다.

## 선택 기능과 검증 범위

- 앞서 작성한 선택형 Orca 의미 기반 UI 어댑터는 기본 꺼짐으로 유지합니다. 기존 네이티브 경로의 필수 의존성이 아니며 설치된 Orca에서의 실동작을 보장하지 않습니다. 이번 핵심 개편은 Mr.Robot 내부 실행 구조입니다.
- 네이티브 오케스트레이션 모의 테스트 16개, 프로젝트·런타임 테스트 14개, 기존 세션 이벤트·AI 루프·기기별 권한·취소 회귀 검사를 통과했습니다. 에이전트·웹 빌드와 모바일 타입 검사를 수행했습니다.
- 실제 유료 모델의 생성 속도를 측정하거나 모든 메모리 누수 제거를 보장한 릴리스는 아닙니다. CLI 지원에 따라 실시간 추가 지시를 사용할 수 없는 공급자는 기존 후속 실행 방식을 유지합니다.
- PC 설치 마법사, 공개 소스 ZIP 및 SHA-256 체크섬을 제공합니다. 계정·페어링·플러그인 연결 상태, 개인 파일과 서명 키는 배포에 포함하지 않습니다.
