# Mr.Robot 0.6.12

순차 오케스트레이션에서 사용자가 지정한 마지막 CLI 모델을 그대로 실행하도록 수정했습니다. 혼합 모델 비교를 준비하면서 발견한 실행 경로 오류이며, 모델 가중치 학습이나 기본 모델 변경은 아닙니다.

## 선택한 최종 모델 유지

- 이전에는 앞 단계의 의견을 모은 뒤, 네이티브 실행이 가능한 최종 CLI 모델도 API 도구 호출을 지원하지 않는다는 이유로 다른 도구 실행 공급자에 넘길 수 있었습니다. 선택한 Astra 대신 다른 API 모델로 끝난 실제 사전 검사에서 이를 확인했습니다.
- 이제 순차 파이프라인도 단일 실행 및 회의형 실행과 같이, 기존 네이티브 실행 조건을 만족하면 선택한 마지막 모델이 결과를 완성합니다. 해당 모델의 실패를 다른 모델의 성공으로 바꾸지 않습니다.
- 단계 시작 상태에 실제로 선택된 모델명을 표시합니다. 그래프에 저장된 이름만으로 혼합 모델 실행을 판정하지 않고, 단계 상태와 최종 실행 경로도 확인할 수 있습니다.
- 기존 승인, 읽기 전용, 사용자 격리, 취소, 사용량 검사를 유지합니다. 일반 Discord 사용자의 작업을 호스트 네이티브 실행으로 승격하지 않습니다.

## 검증 범위

새 회귀 검사는 최종 모델과 이전 단계 근거 전달, 승인 거절, 격리된 실행의 호스트 접근 차단, 최종 모델 실패 시 임의 대체 방지를 다룹니다. 대회 문제 실측과 검사 결과는 [혼합 모델 평가 기록](OBSERVATION_0.6.12_2026-10-03.md)에 별도로 기록합니다.

모바일 버전 메타데이터도 맞췄지만 APK, Drive 및 GitHub Release 바이너리 게시와는 별개입니다. 이번 변경은 사용자 기본 라우팅이나 연결된 계정 권한을 바꾸지 않습니다.
