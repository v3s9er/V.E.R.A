# V.E.R.A 0.7.7

## Discord 추론 설정 안내 수정

- 모델이 현재 실행의 공급자·모델·실제 전달한 추론 옵션을 함께 받습니다. 저장한 `xhigh`가 정상 전달되어도 모델이 ‘확인 불가’라고 답하거나 작업 분류 `standard`를 추론 강도로 혼동하는 원인을 수정했습니다.
- 관리자 전용 작업 상태에서는 **관리자 지정값**과 **최근 종료 실행의 전달값·시각·성공 여부**를 구분합니다. 실행 기록이 없거나 자동 추론의 공급자 내부 기본값을 확인할 수 없으면 명시합니다. 이는 전달 옵션의 확인이며 내부 추론 과정이나 추론량 측정이 아닙니다.
- 일반 이용자에게 모델 설정 메뉴나 관리자 실행 기록을 노출하지 않습니다. 상태 조회와 안내 변경은 사용자별 공급자·모델·추론 지정값, PC 권한, 티켓 대화를 수정하지 않습니다.
- 바뀌는 실행 안내는 세션의 고정 지시문 대신 턴별 문맥으로 전달합니다. 추론 옵션 변경만으로 기존 구독 세션을 새로 만들지 않습니다. 기존 단순 요청의 낮은 추론 처리와 명시적 설정은 구분하며 해당 처리 정책 자체는 바꾸지 않았습니다.

## 검증 및 배포 범위

실제 에이전트 루프의 API·네이티브·격리 Discord 브로커·단순 텍스트 경로에서 실행 옵션과 안내값이 일치하는지 검사했습니다. 모의 app-server 및 설치된 CLI를 로컬 모의 공급자에 연결하여 `xhigh` → `high` 전달과 따뜻한 세션 재사용을 검증했습니다. 실서비스 모델의 응답 정확도나 성능 평가 결과는 아닙니다.

Discord 권한·티켓·첨부·암호화 전송, 모델 튜닝, 세션 이벤트 및 오케스트레이션 회귀 검사를 포함합니다. 테스트에는 합성 사용자만 사용하며 사용자 설정·대화·토큰·개인 백업은 소스와 배포 파일에 포함하지 않습니다.

Windows 데스크톱과 PC 에이전트 업데이트입니다. APK는 새로 배포하지 않으며 공개 Android APK는 0.7.2(versionCode 48)를 유지합니다. 모바일 소스 버전은 0.7.7로 동기화하고 다음 APK 배포 전에 versionCode를 올려야 합니다. 기존 설치 ID·프로필·페어링, MIT 라이선스 및 제3자 고지는 유지합니다. Windows 설치 파일은 미서명입니다.
