# V.E.R.A 0.7.5

## 프로젝트가 많아도 간결한 대화 목록

- 현재 목록에서 최근 사용한 프로젝트 5개를 우선 표시합니다. 선택된 프로젝트와 대화, 실행 중이거나 고정한 대화가 있는 프로젝트는 최근 순위 밖이어도 유지합니다.
- 나머지 프로젝트는 `프로젝트 N개 더 보기`로 펼치고 `최근 프로젝트만 보기`로 다시 접습니다. 검색은 숨겨진 프로젝트와 대화까지 찾습니다.
- 프로젝트는 처음에 한 줄로 접혀 표시됩니다. 직접 펼치거나 새 대화를 만들면 해당 목록이 열리며, 검색으로 선택한 대화도 검색을 지운 뒤 찾을 수 있습니다. 기존에 직접 접어둔 설정은 유지합니다.
- 빈 프로젝트마다 반복되던 안내문을 제거했습니다. 빈 프로젝트를 직접 펼치면 대화 시작 버튼을 사용할 수 있습니다.
- 프로젝트 없는 대화와 연결 해제된 프로젝트의 대화는 바로 아래에 폴더 없이 표시합니다. 기록을 삭제·보관·이동하거나 프로젝트 연결을 변경하지 않습니다.

## 검증과 적용 범위

프로젝트 89개 중 현재 목록에 대화가 없는 프로젝트 67개가 있는 모의 데이터로 최근 목록, 전체 보기, 검색, 선택 유지, 일반 대화 표시 검사를 통과했습니다. 1280px PC, 992×530px 낮은 창, 390px 모바일 브라우저 크기에서 프로젝트 생성·이름 변경·연결 해제, 보관함, Discord 분리를 확인했습니다. 전체 UI 회귀 검사에는 작업 중 대화 전환·취소·추가 지시, 모델 선택과 달력도 포함되며 모두 통과했습니다. 타입 검사, 프로덕션 빌드, 버전 정합성, 브랜드·프로필 유지 검사도 통과했습니다. 사용자 계정·실제 모델을 호출하지 않는 격리된 UI 검사이며 AI 성능 측정 결과가 아닙니다.

Windows 데스크톱과 PC 에이전트의 웹 화면 업데이트입니다. 별도 React Native Android APK는 새로 배포하지 않습니다. 공개 APK는 0.7.2(versionCode 48)를 유지하고 소스 버전만 0.7.5로 동기화합니다. 다음 APK 배포 전 versionCode를 올려야 합니다.

기존 설치 ID, 사용자 프로필, 대화·프로젝트·페어링, MIT 라이선스와 제3자 고지는 유지합니다. Windows 설치 파일은 미서명 빌드입니다.
