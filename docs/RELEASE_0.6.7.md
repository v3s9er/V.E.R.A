# Mr.Robot 0.6.7

## 응답 지연과 스트리밍

- 도구 없는 Codex 답변은 내부 JSON 포장과 완료 대기 없이 일반 텍스트를 스트리밍합니다. 도구 요청이 있는 격리 실행은 기존 검증 프로토콜을 유지합니다.
- 같은 모델·공급자·실행 환경의 유휴 텍스트 프로세스는 재사용하되, 다른 대화에는 반드시 새 임시 스레드를 만듭니다. 기존 스레드의 구독 해제 확인 전에는 새 대화를 시작하지 않습니다.
- 대화 기록, 이미지 중복 제거 정보, 토큰 카운터는 대화 사이에 공유하지 않습니다. 도구를 가진 브로커/네이티브 작업에는 이 프로세스 재배정이 적용되지 않습니다.
- 지연 측정에 대기열, 프로세스 초기화, 스킬 확인, 스레드 생성, 요청 접수, 첫 글자, 완료 시점을 추가했습니다. 허용된 단계명과 숫자만 저장하며 원문 프롬프트·인증 토큰·비공개 추론 내용은 기록하지 않습니다.
- 조각 출력과 최종 출력의 일치, 중복 완료, 다른 스레드의 출력, 취소·실패, 응답 크기 제한을 검사합니다. 새 스레드 재배정도 횟수와 유휴 시간을 제한합니다.

## 유지되는 설정과 보안

선택 모델을 자동으로 낮추지 않습니다. 단순 요청만 기존 적응형 실행에 따라 낮은 추론으로 처리하고, 저장된 높은 추론·Daybreak·PC 권한 설정은 바꾸지 않습니다. 권한 검증, 계정 경계, 네이티브 도구 차단, 비정상 종료 시 재연결 대기는 유지합니다. 백그라운드 예열용 모델 호출이나 유료 우선 처리 모드를 추가하지 않았습니다.

## 검증 범위

설치 앱의 인증된 `chat.start` 경로로 같은 Astra 모델의 변경 전/후 첫 응답과 대화 기억을 반복 측정합니다. 전체 회귀 테스트와 실제 설치 CLI + 합성 로컬 공급자 테스트를 함께 사용합니다. 합성 테스트는 모델 정확도나 실제 네트워크 속도 측정으로 취급하지 않습니다.

모든 외부 모델 응답 시간을 보장하는 업데이트는 아닙니다. 모델/네트워크 대기와 앱 내부 지연은 구분해서 보고합니다. 상세 측정 결과는 `OBSERVATION_0.6.7_2026-10-03.md`를 참고하세요.

모바일 소스 버전은 0.6.7 / Android 35입니다. 별도 APK 빌드·배포를 뜻하지 않습니다.
