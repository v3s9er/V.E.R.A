# Mr.Robot 0.4.13

## 대화 파일 다운로드

- PC의 절대 파일 경로를 답변에 적으면 다운로드 카드로 표시합니다. 한글·공백·대괄호 파일명을 지원합니다.
- PC 앱은 저장 대화상자, 모바일은 암호화 다운로드 후 저장·공유 화면을 엽니다. 모바일 파일 보안 연결이 등록되어 있어야 합니다.
- 서버가 실제 대화의 AI 답변, 기기 파일 전송 권한, 허용 폴더를 확인합니다. 작업 폴더 파일 또는 PC·기기·대화 모두 전체 접근인 경우 Downloads 파일만 허용합니다.
- 알려진 인증 저장 경로/키 파일, 폴더 탈출, 임의 URL은 이 다운로드 기능으로 허용하지 않습니다. 권한은 자동으로 올리지 않습니다.
- 모바일 암호화 전송은 기존 파일당 96MB 한도를 유지합니다. 파일 전송 자체는 AI를 호출하지 않습니다.

## 진행 표시와 스크롤

- 모바일 대화를 최신 메시지 하단 기준 목록으로 바꿔 키보드 표시와 긴 응답으로 인한 하단 잘림을 수정했습니다.
- PC에서도 메시지·입력창 높이 변화와 사용자의 스크롤을 구분합니다.
- PC/모바일에서 진행 단계와 최근 활동 기록을 펼쳐볼 수 있습니다. 중단은 접근성 이름이 있는 사각형 정지 아이콘입니다.
- Codex CLI의 공개 진행 설명/도구 실행 이벤트, Claude CLI의 스트리밍 도구 상태를 표시합니다. 비공개 thinking 원문은 표시하지 않으며 가짜 추론을 생성하지 않습니다.
- CLI UTF-8 조각을 안전하게 합치며, 진행 기록은 최근 20개로 제한합니다.

## 검증 범위

Android 36.1 에뮬레이터의 실제 키보드에서 스트리밍 응답, 8줄 입력, 키보드 3회 열기/닫기, 기본/150% 글꼴, 세로/가로 입력·정지 버튼을 검사했습니다. 세로 화면에서 최신 응답의 마지막 줄도 좌표로 검증했습니다. 실제 사용자 휴대폰 및 iOS 실기기는 이번 검사 범위가 아닙니다.

PC와 모바일 모두 0.4.13으로 업데이트해야 새 대화 다운로드 기능이 동작합니다. 기존 원격 연결과 파일 암호화 등록은 유지됩니다.
