# Mr.Robot 0.2 사용 가이드

## 처음 실행

1. Windows 설치본을 실행합니다. 첫 실행 마법사가 Node.js, Git, Codex CLI,
   Claude Code, Tailscale, Docker Desktop을 검사하고 없는 필수 항목만 설치합니다.
2. `대화` 상단의 **작업 폴더**에서 폴더를 선택합니다. `선택 안 함`도 가능하지만
   Codex/Claude Code로 파일 작업을 하려면 폴더를 지정하는 편이 안전합니다.
3. `설정 → AI 제공자`에서 제공자를 연결합니다. 연결 뒤에도 대화마다 제공자,
   발견된 모델, 추론 강도를 자유롭게 바꿀 수 있습니다.
4. 대화에서 **시나리오 선택 안 함**은 단일 모델입니다. Codex/Claude 구독 CLI와
   작업 폴더를 골랐다면 공식 CLI가 그 폴더에서 직접 실행됩니다.

## 복합 트리

기본 프리셋은 잠겨 있어 실수로 수정·삭제할 수 없고, 복제한 사용자 프리셋은
자유롭게 바꿀 수 있습니다.

- `스마트 캐스케이드`: 빠르고 싼 모델부터 시작해 복잡하거나 검증 실패일 때만 상승.
- `저비용 고효율 투표`: 서로 다른 저비용 노드가 독립 의견을 낸 뒤 의견을 공유하고
  confidence vote와 검증 노드로 결정.
- `순차 검증`: 분석 → 실행안 → 검증 → 최종 정리. 앞 단계 산출물을 다음 노드에 한 번만 전달.
- `혼합 회의`: 병렬 전문가 그룹 → 상호 비평 → 검증자/최종 모델.
- `CTF Autopilot`: 로컬 무토큰 분류 → 최소 파일 묶음 → 격리 분석 → 결과 재현 검증.

그래프에서는 모든 실행 노드를 모델 노드로 취급합니다. 작은 카드에는 이름/목적만
보이고 클릭하면 역할, 제공자, 모델, 그룹, 회의 라운드와 검증 설정이 열립니다.
2·3·4단계 이상 순차 연결과 같은 그룹 안의 다자 회의/투표를 모두 만들 수 있습니다.

## 실행 중 제어와 권한

- 액세스 선택기는 설정 화면이 아니라 **대화 상단의 모델·시나리오·작업 폴더 옆**에
  있습니다. 값은 대화마다 저장되며 PC/모바일에서 같은 대화로 동기화됩니다.
- **중지**: 해당 대화의 AbortSignal과 네이티브 CLI 프로세스를 종료합니다.
- **명령 끼워넣기**: 실행 중 입력한 지시는 다음 안전한 모델 단계 또는 도구 경계에서
  큐 순서대로 전달됩니다. 네이티브 단일 CLI가 이미 한 번의 응답을 생성 중이면 다음
  실행/재시작 경계에서 반영됩니다.
- `읽기 전용`: 변경 도구 전부 차단.
- `매번 승인`: 변경 직전에 확인.
- `작업 폴더`: 등록 폴더 안 파일 변경은 자동, 폴더 밖/고위험 작업은 확인.
- `전체 허용`: PC에서 해당 연결 기기에 부여한 권한 상한이 허용할 때만 자동 실행.

대화 목록은 우클릭해 고정/고정 해제, 이름 변경, 보관, 삭제할 수 있습니다. 고정 대화는
최근 갱신 시간과 무관하게 위에 남습니다. 모바일에서는 대화 칩을 길게 눌러 고정합니다.

모바일 토큰은 기기별 해시만 저장하며 PC에서 따로 폐기할 수 있습니다. API 키는
Windows DPAPI로 암호화되고 Codex/Claude 로그인 정보는 앱으로 복사하지 않습니다.

## 음성

- 데스크톱: `플러그인 → Voice Wake`를 켜고 호출어/언어/PC 우선 시간을 저장합니다.
  Windows에 해당 언어 음성 인식기가 있어야 합니다.
- Android: 대화의 마이크를 누르고 말합니다. 최초 한 번 마이크 권한을 허용합니다.
- `미스터 로봇, ...`을 PC와 폰이 함께 들으면 같은 5초 wake ID로 claim합니다. PC가
  살아 있으면 PC가 먼저 가져가고, 응답이 없을 때만 약 0.9초 뒤 모바일이 처리합니다.

Android/Windows 운영체제 정책상 앱이 완전히 종료된 뒤 항상 백그라운드에서 듣는
기능은 배터리·개인정보·마이크 제한을 받습니다. 현재 릴리스는 데스크톱 트레이 또는
열린 모바일 대화 화면에서 동작하며, 몰래 상시 녹음하지 않습니다.

## 파일과 외부 연결

`파일`에서 `공유함` 또는 `작업 폴더`를 고르고 업로드/다운로드합니다. 전송은 AI를
거치지 않는 직접 바이트 스트림입니다. 경로 탈출(`..`)은 서버에서 차단하고 작업
폴더 쓰기는 기기 권한 상한을 확인합니다.

데스크톱에서는 파일 여러 개를 채팅 본문에 놓으면 선택한 작업 폴더의
`.mr-robot-uploads`로 올리고 첨부 경로를 입력창에 붙입니다. 파일 화면에 놓으면 현재
열린 공유함/작업 폴더로 바로 전송합니다. 두 경로 모두 모델을 호출하지 않습니다.

- 같은 Wi-Fi: PC 모바일 연결 화면의 LAN 주소/QR 사용.
- 외부망: 두 기기에 Tailscale 로그인 → PC에 표시된 `100.x.x.x` 주소/QR 사용.
- 노트북 1 ↔ 노트북 2: 양쪽 Mr.Robot을 등록한 뒤 공유 파일 `PC에서 가져오기` 사용.

Tailscale은 플러그인으로 상태/피어/주소와 PC 우선 wake claim만 제공합니다. 끄면
Mr.Robot 코어와 LAN 사용은 그대로 남습니다.

## 캘린더와 MCP

`일정` 화면의 캘린더 영역에서 로컬 일정을 추가·삭제하고 ICS로 내보냅니다. 자동
실행이 필요한 일은 같은 화면의 예약 작업을 사용합니다. Google Calendar 동기화는
사용자별 OAuth client/consent가 필요하므로 자격 증명을 번들하지 않았습니다. 현재
릴리스는 안전한 로컬/ICS 경계를 제공하며 이후 provider adapter로 연결할 수 있습니다.

`플러그인 → MCP Host`에는 실행 파일과 인자를 분리해 stdio 서버를 등록합니다. 서버는
필요할 때만 시작하고, 도구 목록/호출은 승인 정책을 따릅니다. 비밀은 MCP 설정 JSON에
직접 쓰지 말고 가능하면 OS 환경/공급자 로그인 저장소를 사용하세요.

## CTF + Docker

소유했거나 명시적으로 허가받은 워게임/CTF에만 사용합니다. `플러그인 → Docker
Sandbox → 이미지 준비`는 `mr-robot/ctf-toolbox:0.2.0`을 한 번 만든 뒤 모든 문제에서
재사용합니다. 기본 프리셋은 파일 형식·해시·문자열 같은 로컬 무토큰 특징을 먼저
뽑고 관련 파일/출력만 모델에 보내며, 최종 검증 노드가 재현 명령과 flag 형식을
판단합니다. 인터넷이 꼭 필요한 단계만 별도 승인으로 네트워크를 켜세요.

## 결과물

- Windows: `release/Mr.Robot-Setup-0.2.0-x64.exe`
- Android: `release/mobile/Mr.Robot-Mobile-0.2.0.apk`
- 소스: 이 프로젝트 폴더와 최종 full-work-product ZIP

설치본과 APK는 개인 개발용 서명입니다. 다른 사람에게 공개 배포하려면 Windows
Authenticode와 Android release keystore/Play signing을 별도로 적용해야 합니다.
