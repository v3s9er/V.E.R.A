# Mr.Robot 0.4.6 — 질문별 예산과 Discord 관리자 권한

## 질문별 토큰 예산

- 입력창의 질문 예산 드롭다운: 절약 64,000 / 표준 256,000 / 고품질 1,000,000 / 자동 / 무제한.
- 새 질문마다 새 예산을 부여합니다. 이전 질문의 사용량은 다음 질문에서 차감하지 않습니다. 복합 트리의 모델 호출과 같은 실행 중 추가 지시는 해당 질문의 예산을 공유합니다.
- 고정 단계는 알려진 실제 사용량으로 정산하며 사용량이 없는 CLI는 예약량으로 추정합니다. 네이티브 CLI 내부 사용량은 종료 후 보고될 수 있어 선택한 예산이 실제 청구량의 엄밀한 상한을 보장하지는 않습니다.
- 무제한은 Mr.Robot이 토큰 수 때문에 작업을 중단하지 않는 모드입니다. 공급자 요금·계정 한도·모델 컨텍스트 크기·반복 방지·동시 실행 보호는 유지됩니다.
- 인증된 실행 가능 PC/웹/연결 기기는 무제한을 선택할 수 있습니다. 별도의 PC 관리자 설정 권한을 부여하지 않습니다. 읽기 전용 연결은 실행 불가 상태를 유지합니다.
- 긴 실행의 10~15분 RPC 대기 타이머를 제거했습니다. 연결 해제·취소·완료에 따른 정리는 유지합니다.

## Discord

- 기존 봇 소유자 전용에서 등록된 서버의 Administrator 권한 사용자 전용으로 변경했습니다. 서버/역할 정보를 매 요청마다 다시 조회하며 DM과 미등록 서버는 거절합니다. 서버 관리(Manage Guild)만으로는 허용하지 않습니다.
- `/robot access mode:<read-only|ask|workspace|full>`: 서버·채널·사용자별 권한. full은 `confirm_full:True`를 명시해야 합니다.
- 이 명시적인 full은 해당 Discord 실행에서만 전체 PC 접근을 허용합니다. 앱 전체 설정을 변경하지 않으며 PC의 읽기 전용 비상 잠금은 유지합니다. 일반 원격 연결이 JSON 필드로 이 권한을 위조할 수 없습니다.
- Discord는 기본 무제한입니다. `/robot result`로 긴 작업 결과를 다시 조회하고 `/robot approval`로 승인 버튼을 다시 받습니다. 결과는 프로세스 메모리에만 제한적으로 보관되며 앱 재시작 후에는 PC 대화 기록에서 확인합니다.
- 승인과 결과는 요청자별로 분리합니다. 실행 중 관리자 권한 회수를 주기적으로 확인하여 작업을 취소합니다.

## 검증

- 질문별 초기화·단계 한도·무제한 네이티브 사용량, Discord 서버/관리자 검사·full 동의·타인 승인 차단 테스트.
- 로컬 전용 권한 위조 방어·관리자 설정 권한 비승격·읽기 전용 비상 잠금·회수 테스트.
- Shared/Agent/Web/Mobile 타입 검사, 기존 코어/AI 실행/데스크톱 인증 및 PC·모바일 UI 회귀 검사.
- 모바일 소스에도 질문 예산 선택을 반영했습니다. 이 작업은 Windows 설치본 적용을 대상으로 하며 기존 APK를 새 버전으로 가장하지 않습니다.

Discord 연결은 PC가 켜져 있고 앱이 실행 중이어야 합니다. Discord 메시지는 종단간 암호화가 아니므로 비밀정보를 입력하지 마세요.
