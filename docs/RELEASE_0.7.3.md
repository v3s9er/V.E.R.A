# V.E.R.A 0.7.3

## PC·웹 대화 목록 정리

- 프로젝트 목록과 대화 목록을 하나의 트리로 통합했습니다. 프로젝트별로 대화를 접고 펼치며 같은 위치에서 새 대화를 만들거나 프로젝트 설정을 열 수 있습니다.
- 프로젝트명과 대화 제목을 검색할 수 있습니다. 검색 중에는 일치하는 대화를 펼쳐 보여주며 새 대화를 만들면 검색을 비워 생성한 대화를 찾기 쉽게 합니다.
- 프로젝트마다 최근 대화 5개를 기본으로 표시합니다. 선택한 대화, 실행 중인 대화와 고정한 대화는 최근 5개 밖에 있어도 펼쳐진 프로젝트 안에 유지하며 나머지는 **더 보기**로 열 수 있습니다.
- 대화 제목은 한 줄로 정리하고 날짜·메시지 수는 마우스 안내에 담았습니다. 고정·실행·대기 상태는 작은 표시로 구분합니다.
- 프로젝트 설정을 저장한 뒤 보이지 않는 목록 필터가 남는 문제를 수정했습니다. 다른 프로젝트의 대화를 고정하거나 보관해도 현재 선택한 대화와 작업 폴더가 임의로 바뀌지 않습니다.
- 연결을 해제한 프로젝트의 대화에서 새 대화를 만들면 기존 대화는 변경하지 않고 기본 프로젝트에 새 대화를 만듭니다.
- 프로젝트 및 대화 메뉴의 키보드 접근과 터치 조작을 다듬고 모바일 웹의 메뉴가 목록 뒤에 가려지는 레이어 문제를 수정했습니다. Escape는 최상단 대화 메뉴를 먼저 닫으며 그 뒤의 모바일 목록까지 한꺼번에 닫지 않습니다.
- 내 대화와 Discord 기록은 기존처럼 별도 공간으로 유지합니다. 프로젝트 구분은 PC 접근 권한이나 샌드박스 정책을 변경하지 않습니다.

## 검증 및 배포 범위

사이드바 전용 UI 회귀 검사 `npm run test:sidebar-ui`를 추가하고 전체 UI 검사 `npm run test:ui-live`에 연결했습니다. 검사 대상은 프로젝트별 접기·펼치기, 검색, 최근 대화 표시, 고정·실행·선택 상태와 작은 화면에서의 메뉴 조작입니다. 이 문서는 변경 범위를 설명하며 테스트 실행 결과나 AI 정확도 향상을 대신하지 않습니다.

이번 변경에서 전체 UI 회귀 검사, 전체 패키지 타입 검사, 프로덕션 빌드, 데스크톱 복구·브랜딩 검사, 공개 소스 및 Windows 설치 파일의 민감정보 검사를 통과했습니다. UI 검사는 격리된 브라우저와 모의 RPC를 사용하며 실제 모델이나 사용자 대화는 호출하지 않습니다. 320px부터 1280px까지의 화면과 낮은 창 높이, 실제 하단 프로필 컴포넌트, 터치·키보드 메뉴, 작업 중 대화 전환·초안·중지를 포함합니다.

이번 배포는 Windows 데스크톱과 PC 에이전트가 제공하는 웹 화면의 사이드바 업데이트입니다. 모바일 브라우저에는 갱신된 웹 화면이 적용되지만 React Native Android 앱은 별도 구현이므로 이번에 새 APK를 빌드하거나 배포하지 않습니다. 기존 Android 0.7.2 APK는 그대로 유지하며 이를 0.7.3 APK로 이름만 바꿔 제공하지 않습니다. 소스의 모바일 버전 표시는 저장소 버전과 동기화하되 Android `versionCode`는 48로 유지했습니다. 다음 새 APK 배포 때는 `versionCode`를 올려야 합니다.

기존 설치 ID, 데스크톱 프로필, 대화·프로젝트·페어링, MIT 라이선스와 제3자 고지는 유지합니다. 이번 업데이트는 기존 사용자 데이터를 초기화하지 않으며 Windows 설치 파일은 코드 서명 인증서 없이 빌드됩니다.
