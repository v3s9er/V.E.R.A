# Mr.Robot 0.6.1 — Daybreak, 문맥 관리와 적응형 실행

2026-10-02. 소스·빌드 변경 내역입니다. 설치 적용, GitHub 게시 및 실제 휴대폰 검증 여부는 별도로 확인해야 합니다.

## 사용자가 바로 보는 변화

- PC·모바일 입력창에 **Daybreak 켜기/끄기**를 모델과 별도로 배치했습니다. Codex CLI 또는 공식 OpenAI API의 GPT 모델에서만 표시합니다. 다른 공급자로 바꾸면 꺼지고, 대화별로 저장됩니다. 계정의 실제 사용 자격은 공급자가 확인하며 PC 접근 권한을 늘리지 않습니다.
- 모델 선택을 검색·공급자 필터·선택 표시가 있는 목록으로 정리했습니다. 중복 Daybreak 별칭을 줄이고 모바일의 모델 ID 직접 입력은 접어 놓았습니다.
- 자동 추론에서는 명확한 인사·단순 계산은 가볍게, 일반 요청은 보통으로, 보안 분석 등 복잡한 요청은 깊게 처리하도록 실행 지침을 적용합니다. 짧은 문장이라는 이유만으로 단순 작업으로 취급하지 않습니다. 사용자가 직접 정한 추론 단계가 우선하며 선택 모델을 임의로 바꾸지 않습니다.
- 중단된 실행은 완료 여부를 확인하라는 안내를 표시합니다. 전송·삭제 같은 작업을 자동으로 다시 실행하지 않습니다.

## 문맥·도구·보안

- 선택한 프로젝트 루트의 `AGENTS.md`만 제한된 크기로 읽습니다. 프로젝트 지침이 시스템 권한을 바꿀 수는 없습니다.
- 장기 기억에 프로젝트·대화 범위와 출처를 추가했습니다. 관련 없는 기억은 주입하지 않으며, 간단한 관계형 사실과 변경 이력을 설정에서 관리할 수 있습니다.
- 대화 압축은 뒤쪽의 조건·미완료 사항과 근거를 보존하도록 개선했습니다. 원본 기록은 유지합니다.
- 큰 MCP 결과는 잘라 버리는 대신, 대화·작업 폴더·권한에 묶인 임시 참조로 필요한 부분을 읽습니다. 서버 삭제/설정 변경과 만료 시 참조를 폐기하며 읽기 때문에 원래 도구를 재실행하지 않습니다.
- 끊어진 심볼릭 링크/정션을 통한 경로 검증 우회를 회귀 테스트로 확인해 수정했습니다. 파일 읽기의 교체 검사를 강화했지만 OS 수준 격리를 대체한다고 주장하지 않습니다.
- Electron을 43.7.7로 올리고 호환 범위 내 보안 의존성을 갱신했습니다. 루트·모바일 의존성 감사에서 알려진 취약점 0건을 확인했습니다. 애플리케이션 전체의 무결함을 의미하지는 않습니다.

## 검증과 성능 해석

타입 검사, 전체 자동 테스트, 권한·암호화·세션·튜닝 회귀, 좁은 화면의 웹 UI, 제한된 반복 실행 누수 검사를 수행했습니다. 정확한 `gpt-6-sol` 모델로 Daybreak Blue 요청과 도구 없는 방어적 소스 검토도 확인했습니다. 인증정보를 복사하거나 다른 모델로 대체하지 않았습니다.

BFCL 공개 문제의 작은 별도 검증군에서는 medium/low 모두 11/12였지만 low의 P95가 20.71초에서 67.63초로 악화됐습니다. 따라서 모든 요청을 low로 바꾸는 튜닝은 채택하지 않았습니다. 공식 대회 점수나 앱 전체 성능 향상을 입증한 결과가 아닙니다.

추가로 AIME 대회 문제의 고정 데이터·정답 분리·엄격한 채점 회귀 검사기를 추가했습니다. 실제 AgentLoop 경로의 Sol 6 실행 조건과 성적은 [대회 문제 검사 결과](COMPETITION_RESULTS_2026-10-02.md)에 기록합니다. 공개 문제의 학습 포함 가능성이 있으며, 앱 전체 정확도나 공식 리더보드 점수로 해석하지 않습니다.

구독 모델의 가중치 파인튜닝, 모든 공급자의 컴퓨터 제어 교체, 실제 Android 키보드 검증, 외부 대상 침투는 완료된 작업으로 표현하지 않습니다. 기존 로컬 학습 기능은 계속 명시적인 사용자 실행과 적합한 모델·자료가 필요합니다.

Windows 설치본은 코드 서명 인증서가 없는 개발 빌드입니다. Android는 기존 서명 ID를 유지하며 versionCode는 31입니다. 상세 구현·실험 범위는 [검증 기록](UPDATE_2026-10-02.md)을 참고하세요.

## Windows에서 APK 재빌드

긴 경로와 한글 경로를 피하도록 새 ASCII 작업 폴더를 생성합니다. 기존 폴더를 덮어쓰지 않습니다. SDK/JDK와 기존 공식 서명 자료는 별도로 필요하며 저장소에 포함하지 않습니다.

```powershell
$buildPath = & .\scripts\stage-mobile-source.ps1
Push-Location $buildPath
try {
  npm ci
  if ($LASTEXITCODE -ne 0) { throw 'Root dependencies failed' }
  npm ci --prefix apps/mobile
  if ($LASTEXITCODE -ne 0) { throw 'Mobile dependencies failed' }
  & .\scripts\build-mobile-release.ps1
} finally { Pop-Location }
```
