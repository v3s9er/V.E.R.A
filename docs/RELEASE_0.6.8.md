# Mr.Robot 0.6.8

## 대화·세션 안정성

- 네이티브 에이전트와 Discord 격리 도구 실행에서 여러 공개 메시지가 나왔을 때 마지막 메시지만 저장되던 문제를 수정했습니다. 스트리밍과 최종 대화 기록을 일치시키고 후속 세션 재사용을 검증합니다.
- 완료 후 추가 델타, 내용이 바뀐 중복 완료, 순서가 뒤섞인 메시지, 미완성 출력을 정상 완료로 저장하지 않습니다. 답변 전체 크기와 메시지 개수도 제한합니다. 비공개 추론은 출력하지 않습니다.
- 세션 재구성 때 JSON 중간을 자르지 않고 최근 대화를 유효한 레코드 단위로 전달합니다. 오래된 기록 생략 또는 큰 기록의 부분 발췌는 명시하며, 도구 호출·결과는 가능하면 같은 묶음으로 유지합니다. 원본 대화는 삭제하지 않습니다.
- 실행 환경이 달라지면 기존 네이티브 프로세스와 체크포인트를 재사용하지 않습니다. 환경 식별에는 해시만 사용하고 환경값은 기록하지 않습니다.
- 네이티브 작업에도 대기열·초기화·접수·첫 출력·완료/실패 시간 측정을 추가했습니다. 프롬프트, 파일 내용, 인증정보, 비공개 추론은 이 측정 기록에 넣지 않습니다.

## UI와 검사

- 좁은 창의 Daybreak 버튼이 입력창 밖으로 밀리던 문제를 수정했습니다. 작은 화면에서는 아이콘으로 표시하고 버튼의 접근성 이름·켜짐 상태·설명을 유지합니다. 공간이 부족하면 설정 줄을 줄바꿈합니다.
- UI 검사를 별도 수동 개발 서버 없이 실행할 수 있습니다. 임시 로컬 서버, 전용 브라우저 프로필, 모의 데이터만 사용하며 실제 PC RPC와 외부 통신은 차단합니다. 테스트 도중 HMR이 상태를 초기화하지 않도록 했습니다.
- `npm run test:ui-live`로 입력창 7개 크기, 모델 선택 3개 크기, 일정/플러그인 캘린더 5개 크기를 검사합니다. 보내기뿐 아니라 모든 입력창 버튼의 경계도 확인합니다.

선택 모델, 저장된 추론 강도, PC 권한은 유지합니다. 모델 자동 하향, 유료 우선 처리, 계정 공유 또는 백그라운드 모델 예열을 추가하지 않았습니다. 일반 작업이 항상 빨라졌다는 주장은 하지 않습니다. 측정과 제한은 `OBSERVATION_0.6.8_2026-10-03.md`에 구분합니다.

모바일 소스 버전은 0.6.8 / Android 36입니다. 반응형 웹 검사는 Android APK나 실제 휴대폰 키보드 검사를 대신하지 않습니다. 이번 작업에는 APK 빌드·배포가 포함되지 않습니다.
